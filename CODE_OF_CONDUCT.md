# Code of conduct

This project is for people who want Bannerlord Coop to work well for everyone. Be someone others are glad
to work with.

## What we expect

- Be kind and patient, also with people who are new to modding, C# or GitHub.
- Talk about the code and the change, not the person.
- Take feedback on a PR as help, and give it the same way.
- Keep player data private. Never post someone's name, Steam id, IP address, email or logs without their
  OK.

## What is not OK

- Insults, harassment, threats or slurs, in issues, PRs, commits or anywhere else in the project.
- Unwelcome sexual content or attention.
- Posting someone's private information.
- Spam, trolling, or flooding issues and PRs.

## What happens

Coodsz looks at every report and decides what to do. That can be a warning, a removed comment, or a ban
from the repository and the Coodsz Discord.

To report something, message Coodsz on Discord (Coodsz) or on GitHub (github.com/Coodsz). Reports are
kept private.
