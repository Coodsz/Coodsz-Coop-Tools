# Agent instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing this repository. Claim a linked issue before implementation and follow the checklist in [.github/pull_request_template.md](.github/pull_request_template.md).

Claude authored changes need independent Codex review. Use High reasoning or higher for substantive work. Codex authored changes need independent Claude review. Ask a maintainer to arrange review if needed.

Review the exact PR head, its diff, and the surrounding code. Verify each finding against the code and cite its file and line. Report tests run and verification gaps. Recheck blockers against the updated head.

Agents need approval from their operator to push, open a PR, or post a comment. Maintainers approve merges. Keep private reports, logs, and credentials out of public PRs and issues.
