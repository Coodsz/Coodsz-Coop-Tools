**Coodsz AD1259 tools v1.0.15 are out**

A small privacy fix. Click Install update in the client launcher and the server tool.

**Your join password stays out of the log zips**
The client launcher starts the game with the join password, and the game writes that into its own logs. Save logs for help used to pack it as it was. Now the password is taken out before anything goes in the zip, in both tools.

**If you already shared a log zip**
Zips made with older versions may have your join password in them. If you sent one to anyone, it is a good idea to change your server password in the server tool and tell your players the new one.

AD1259 coop fixes are by SkyApolo, bundled with permission. Let me know in this thread if anything acts up.
