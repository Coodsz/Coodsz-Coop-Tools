### What is new in v1.2.15

**Client Launcher, Connect.** Clicking **Connect** again while the game starts no longer opens a second Bannerlord. Before, a few quick clicks could start two games, and the second one crashed.

**Client Launcher, Safe mode.** Each **Safe mode** click now joins with Plain TAOM, even two quick clicks in a row. Safe mode also says before the game starts that it only works when the host runs Plain TAOM too.

**Client Launcher, crashes.** After a crash, the Client Launcher no longer blames Better Exception Window just because it loaded last.

![The Coodsz TAOM download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-TAOM/main/images/Coodsz-TAOM-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.15.zip` and copy each program over the old one.

New text is translated into all nine languages.
