### What is new in v1.3.12

**Server Tool, saves on the Coop nightly.** A campaign played on the Coop nightly no longer disappears from the saves after its first stop. When a mod's version changed since a save was made, the **Logs** page now names that mod and both versions instead of saying the mods don't match.

**Server Tool, Logs page in your language.** The **Logs** page now shows its What happened, What to do and What not to do lines in the language you picked. Before, they stayed in English.

**Server Tool, a frozen map when the server's own hero is a prisoner.** Save Rescue now keeps the map moving when a save has the server's own hero, the one nobody plays, as a prisoner (seen with TAOM). Before, the server kept opening a captivity menu and every party stood still. The hero stays a prisoner, and nothing else in the save changes.

The Client Launcher only got a new version number.

![The Coodsz Coop download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-Coop-and-Friends/main/images/Coodsz-Coop-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Coop-Tools-v1.3.12.zip` and copy each program over the old one.

New text is translated into all six languages.
