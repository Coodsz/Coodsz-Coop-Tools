### What is new in v1.1.50

**A male child being born no longer stops the server.** Coop 0.1.6 crashed on the daily tick when a boy was born. Coop Save Rescue, which the server tool already loads on every start, now fills in the missing name first, so the server keeps running. Update the server tool and load your save again.

**Version numbers stay readable in reports.** Crash reports and log zips from the TAOM client launcher and server tool now show version numbers like 3.0.3.0 as they are, instead of hiding them like an address. Real IP addresses are still taken out.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
