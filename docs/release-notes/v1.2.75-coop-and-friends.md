## Small fixes

**Messages name the right button.** Some messages in Coop and Friends said to click Refresh, but that window has no Refresh button. They now say Check mods. A few more lines are translated, and a word in What's new lost its hyphen.

**Safer updates.** Install update now checks that the download really comes from the Coodsz GitHub page and matches the release before it replaces any file. If a check fails, your old files stay as they are.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
