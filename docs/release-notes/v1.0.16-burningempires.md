### What is new in v1.0.16

**Server Tool, Console page.** The server output box is tall enough to read again. Before, it could shrink to one thin line, so replies to your commands were hard to see.

**Server Tool, War Sails.** Start server and **Test mods on the server** now stop with a clear line when War Sails is turned on, because these tools can't host War Sails yet. The line says where to turn it off.

**Server Tool, Saves page.** When Prepare server stops, the Saves page now shows why, not only the Dashboard. When Windows blocks a DLL the server needs, the tool now opens Settings, where the red **Unblock DLLs** button is.

**Server Tool, mod lists.** **Share mod list** now writes each mod's version from the copy your next Start server uses, so a Workshop update shows in the list right away. A mod listed twice in a setup no longer crashes **Share mod list**, the mod checks or **Auto sort**.

**Server Tool, staying up.** When something goes wrong that the tool did not expect, it now says so on the status line and keeps running, instead of closing while the server is still up. The player list no longer goes blank when the server writes a broken players line, and a player name or chat line can no longer change the list.

**Client Launcher.** The game command line it shows when you click **Connect** now hides your join password, so it stays off streams and screenshots. A mod listed twice in a setup no longer crashes **Find the crashing mod**.

**Both tools, the license.** The license now also names the Coodsz Realm of Thrones tools. The tools ask you to accept it once more. The license itself stays in English.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.16.zip` and copy each program over the old one.

New text is translated into all nine languages.
