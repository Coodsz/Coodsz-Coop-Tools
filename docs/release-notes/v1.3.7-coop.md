### What is new in v1.3.7

**A new look.** Both tools have a sidebar with their pages. The Server Tool opens on the new **Dashboard**, with **Saves**, **Mods**, **Settings**, **Logs** and the other pages under it. The Client Launcher opens on **Play**, with **Mods**, **Logs and help** and **Settings**. A picture sits behind the pages, and only one notice shows at a time.

**The mod list is locked while the server runs.** On the Server Tool's **Mods** page the switches, the move arrows and **Save module config** are off while the server runs, so the server keeps the mods the players joined with. **Go to Dashboard** on the banner takes you to **Stop server**. A setup you pick meanwhile is used at the next **Start server**.

**Dashboard cards.** The **Mods** card shows how many mods are on, and the **Versions** card shows the Bannerlord and Coop versions the server has.

**Clearer chip words.** Required is now **Always on**, Update is **Needs update** and Version is **Wrong version**. A Workshop mod that is not on this PC says **Missing on Workshop**, and Coodsz modules get a **Coodsz module** chip.

**The crash report bar waits.** When the Server Tool tries a load crash again by itself, the **Send server crash report** bar waits for that try and shows only if it crashes too.

**Smaller fixes.** When the host has no mod settings to share, the server now says so, and the player's game no longer waits 30 seconds for them. **My reports** keeps checking for answers after the PC clock was set back.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Coop-Tools-v1.3.7.zip` and copy each program over the old one.

New text is translated into all six languages.
