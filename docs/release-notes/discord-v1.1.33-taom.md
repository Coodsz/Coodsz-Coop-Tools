# Discord announcement, Coodsz TAOM tools v1.1.33

Paste the text inside each block as its own message, the first one first. Each stays under 2000 characters, has no colons and no hyphens between words.

```
**Coodsz TAOM tools v1.1.33 are out**

You can finally play TAOM coop with more mods. Click Install update in both tools.

**Mod setups**
Plain TAOM stays exactly the sealed set you know. TAOM plus is a locked set of mods I tested in coop with TAOM, like RTS Camera, Improved Garrisons, Banner Fix and Dismemberment Plus. Or make your own setup with Add mods. The new Mod list window shows which mods were tested, which ones load on the server and which ones are risky, and Add to setup puts one in with a click. TAOM community mods and patches with TAOM_ names can be added too.

**The launcher handles the annoying stuff**
Mods that ask for Harmony, ButterLib, UIExtenderEx or MCM get fixed to use TAOM.Dependencies before each launch, and put back after. DLLs get unblocked by themselves. Auto sort puts your mods in the order the TAOM team asks for, and Connect checks for missing or clashing mods first.

**When it crashes**
Find the crashing mod tests your extra mods in halves until it finds the bad one. Safe mode joins once with Plain TAOM. Save logs for help makes the zip to send me.

**Server tool**
It can now run a server with your extra mods, and you can edit your setups right there like in the client. Test mods on the server tries each mod alone on a copy of your save and tells you if it loads. Stop and Restart wait until the save is really written, so you no longer lose progress on the next start. Your campaign gets a backup after every save. It shows a loading bar while it starts, FAILED with a reason when a save will not load, and warns about saves from another TAOM version.

**Joining**
The server tool shows the addresses friends can use with Copy buttons, Copy invite makes a Discord message without your password, and it can open the port on your router for you. Playing on the same PC fills in 127.0.0.1 by itself.

There are fewer buttons on screen too, and the rest sit in the More menus. Tell me in this thread if anything breaks.
```

```
**Two more things in the TAOM server tool**

**Add mods to a running campaign**
If your setup only adds mods to a save, the tool asks once and keeps a copy of the save before it starts. A save that needs mods your setup leaves out gets a big warning, because taking mods out can break the campaign.

**Game speed**
The Server page now shows whether 2x speed and the battle speed limit are on, with buttons to change them and a Restart server button when it is needed. On the Settings page the fast forward options sit in a Game speed group at the top.
```
