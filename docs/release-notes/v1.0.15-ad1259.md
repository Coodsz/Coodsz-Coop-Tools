## Your join password stays out of the log zips

- **Save logs for help now takes your join password out of the logs.** The client launcher starts the game with the join password on its command line, and the game writes that line into its engine and watchdog logs. The log zip used to keep it. The zip now replaces it with [password], in the client launcher and in the server tool.
- **More places are cleaned.** A quoted password (two words in quotes) now goes as a whole, settings files in a crash report folder (.ini, .cfg) are cleaned like the other logs, and a zip inside a crash report folder is unpacked so its logs are cleaned too.
- **If you already sent a log zip to someone,** it may have your join password in it. Change the server password in the server tool if that worries you.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
