### What is new in v1.2.1

**Everyone should update, players too.** The party size fix below also runs on each player's PC, so players need the new **Coodsz TAOM Client Launcher** as well as the host's new Server Tool.

**TAOM party sizes count again with Improved Garrisons.** With Improved Garrisons in your setup, TAOM's own party sizes count again, and so do the Party settings on the Server Tool's Settings page. Improved Garrisons used to replace them on the server and on every player's PC.

**No more CompatOnly downloads.** The Client Launcher now has the TAOM-Coop CompatOnly CLIENT zip built in and the Server Tool has the HOST-OPERATOR zip. A copy you already have on this PC is still used first. The two zips stay on this page for anyone who wants them.

**Births no longer stop the server.** A child born to a player's character used to stop the server. Coop Save Rescue now fills in what the game needs before the birth, so the server keeps running.

**Buttons wait for Start server.** While Start server is getting ready, Stop, Restart, Save game, Last good save, Install mods and Test mods on the server now ask you to wait.

**Server commands wait for the answer.** A command the server turned down no longer shows as done.

![The Coodsz TAOM download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-TAOM/main/images/Coodsz-TAOM-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.1.zip` and copy each program over the old one.

New text is translated into all six languages.
