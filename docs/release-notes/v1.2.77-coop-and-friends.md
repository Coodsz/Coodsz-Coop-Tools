## MCM from Nexus wins over the old Workshop download, and server window letters show right

**MCM from Nexus is the one the launcher uses.** When Mod Configuration Menu (MCM) is both in the game's Modules folder and in the old download from the removed Workshop item, the launcher now uses the Nexus copy in the Modules folder, the same one the host runs. This also works for a setup saved before v1.2.76. Joining no longer fails on an MCM version the host doesn't run. **Connect** also turns off the old Workshop download while the Nexus copy is used, so the game loads only one MCM even when both are the same version, and turns it back on if the copy in the Modules folder is gone. If the old Workshop download is still there, the second copy line says to unsubscribe from it in Steam, then click **Check mods**.

**For hosts: letters like Ü or İ show right in the server window.** Coodsz Host now reads the server window in the PC's own code page, so save names and lines with those letters no longer turn into question marks.

**Crash reports: the crash dump sentence shows only with a dump.** The crash report window now mentions the crash dump only when there is a dump to add.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
