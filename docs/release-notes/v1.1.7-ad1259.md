### What is new in v1.1.7

**Start server fixes a short mod copy.** **Start server** now checks the AD1259 set mods on the server. When it finds missing server files and this PC has the same version of that mod, it copies the mod again. A big copy can take a while, so leave the tool open.

**A missing map stops the start.** When the campaign map files are missing on the server, **Start server** now stops and says what to do. Before, the server started a plain Calradia world and every player who joined crashed.

**One try per copy.** When a copy fails or still misses files, this check leaves it until you reopen the tool.

![The Coodsz AD1259 download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-AD1259/main/images/Coodsz-AD1259-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.7.zip` and copy each program over the old one.

New text is translated into all six languages.
