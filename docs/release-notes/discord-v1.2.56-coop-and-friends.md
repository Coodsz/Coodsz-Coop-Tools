# Discord announcement, Coop and Friends v1.2.56

Paste the text inside the block as one message. It stays under 2000 characters, has no colons and no hyphens between words.

```
**Coodsz Coop and Friends v1.2.56 is out**

A small privacy fix. Click Install update in the tool and you get it.

**Your join password stays out of the log zips**
Bannerlord writes its command line into its own logs. When a game was started with the join password on that line, like the TAOM and AD1259 launchers do, the password stays in those logs, and Save logs for help packed them as they were. Now the password is taken out before anything goes in the zip, in Coop and Friends and in Coodsz Host.

**If you already shared a log zip**
Zips made with older versions may have your join password in them. If you sent one to anyone, it is a good idea to change your server password in Coodsz Host and tell your friends the new one.

Let me know in this thread if anything acts up.
```
