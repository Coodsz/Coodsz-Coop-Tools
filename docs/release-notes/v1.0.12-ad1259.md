## Easier joining

- **The AD1259 server lists the addresses your friends can use.** The Server page has a card with Steam lobby, Radmin VPN, Hamachi, ZeroTier or Tailscale, your public address, same Wi Fi and 127.0.0.1, each with a Copy button.
- **Copy invite** puts a short message for Discord on your clipboard with the address, the port and whether a password is needed. It never includes the password itself.
- **Open the port on my router automatically** (on by default) asks your router to open the server's UDP port while the server runs, and closes it again after the server stops or when you close the tool.
- **Allow through firewall** checks Windows Firewall first and only adds the rule after you confirm and Windows asks for permission.
- **How will friends join?** and the **?** buttons open a short guide for each way to join: Steam lobby, same Wi Fi, Radmin VPN or Hamachi, port forwarding, and playing on the host PC.
- **The client launcher fills in 127.0.0.1 when the server runs on your own PC**, with the server's port. With Radmin VPN or Hamachi on your PC you get a short hint about using the host's VPN address.

## Client launcher

- **Save logs for help** replaces Save all logs to one zip and Open client logs. The small arrow next to it opens the other choice.

## Server tool

- **Restart the server if it crashes** is a new option. It waits longer after each crash and gives up after more than 3 crashes in 10 minutes.
- **A backup after every save.** The last 10 are kept per save. **Load backup** lists them while the server is stopped and keeps a copy of the current save before it puts one back.
- **Stop and Restart let the server save and close by itself**, so the last minutes of play are kept. Restart warns the players 30 and 10 seconds before.
- **The status follows the server's own messages**, so it no longer shows SERVING before the server is ready, and a crash after that is told as a crash.
- **CPU and memory line** while the server runs.
- **Safer bans.** Only real SteamID64 numbers are taken, and the ban list is written in one go.
- **Every Coop setting is on the Settings page**, the rest under **Show more Coop settings**, kept for each campaign save. Numbers outside the allowed range are refused.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
