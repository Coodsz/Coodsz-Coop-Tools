## One zip, two programs

**The Coop tools have new names.** Coodsz Host is now **Coodsz Coop Server Tool**, and Coodsz Coop and Friends is now **Coodsz Coop Client Launcher**. Both come in one zip, `Coodsz-Coop-Tools-v1.3.0.zip`, with nothing else in it. The modules and bundled mods are inside each program.

![The new Coodsz Coop download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-Coop-and-Friends/main/images/Coodsz-Coop-new-download.png)

**Coodsz and Friends is now the More Nations switch** in the client launcher, under **Campaign map**. When it is on, a setup with no saved map starts on More Nations Remastered Map. If you used Coodsz and Friends, its update turns it into the client launcher with the switch on, and your setups and settings come along. If you also used the Coop client launcher, you keep its setups too, and a More Nations setup with the same name shows up with (More Nations) after its name.

**Your settings move by themselves.** They now live in %LOCALAPPDATA%\Coodsz\Coop. Each program copies them there from its old folder on its first start, so keep the old folder until then.

**New icons.** The Server Tool and the Client Launcher each have their own Coodsz banner icon, so you can tell them apart in the taskbar.

**Steam library fix.** A damaged Steam library file no longer stops the tools from finding Bannerlord and the Workshop mods.

### How to update

- **If you already have the tools,** click **Install update**. On its first start the new program takes its new name, moves your Desktop, Start Menu and taskbar shortcuts to itself, and removes the old exe. If a shortcut can't be moved, the old exe stays and the next start tries again.
- **Updating by hand.** Close the tools, download `Coodsz-Coop-Tools-v1.3.0.zip`, and copy each program into the folder of the old one so it finds your settings. Choose Replace if Windows asks.
- **A new install.** Unzip `Coodsz-Coop-Tools-v1.3.0.zip` into a folder of its own.

`Coodsz-Coop-and-Friends-v1.3.0.zip` is only there so older tools can update themselves. You don't need to download it.

New text is translated into all six languages.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. THIRD-PARTY-NOTICES.md is now inside each program and shows under the license.
