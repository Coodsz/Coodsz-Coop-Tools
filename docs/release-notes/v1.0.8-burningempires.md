### What is new in v1.0.8

**Notices from Coodsz.** The tools can now show a notice from Coodsz at the top, in your language, for example while he is on vacation. A crash report bar or a reply to your report still shows first. **Dismiss** hides the notice until its words change.

**Download Coop server.** The Server Tool has a new **Download Coop server** button under **Advanced: server folder** on the **Settings** page. It opens Coop's dedicated server download (about 4.5 GB) in your browser, using the link on Coop's latest release. If that link can't be read, it opens Coop's release page instead. The server download is linked at the bottom of the release notes there, not under Assets. Unzip the download to a short folder like `C:\CoopServer`, then click **Choose Coop server**. When this PC has no Workshop Coop, the message from **Prepare server** names this button.

![The Coodsz Burning Empires download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-BurningEmpires/main/images/Coodsz-BurningEmpires-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.8.zip` and copy each program over the old one.

New text is translated into all six languages.
