## A new Cheats page (Coodsz Host)

- **Pick a player, pick a cheat, press Run.** Player cards sit at the top with each player's gold and age. Under them are the categories Gold, Clan, Skills, Party, Hero and World, plus a star for your favourites.
- **No typing ids.** Each cheat has a short form with dropdowns for skills, kingdoms, towns, villages and heroes, and quick buttons for common amounts.
- **Coop's own commands.** Vanilla campaign cheats do not work in Coop, so every cheat sends a Coop command, and the form shows the exact line under **Sends to the server console**.
- **Undo where it can.** Gold, influence, health, clan tier, renown, age and attribute or focus points can be undone. The admin log lists every change with the line it sent.
- **Everything from before is still here.** Health, the troop basket, items, clan tier, the character sheet and the player profile all moved into the new layout.

## A new Console page (Coodsz Host and the AD1259 server)

- **Every Coop command in one list.** All 414 commands, with the categories down the left and a search box. Each one is tagged Server, Both or Client.
- **A How to use guide for each command.** It says in plain words what the command does, what each value means, and where to find it.
- **One click examples.** **Use example** fills in the boxes, and **Find ids** runs the list command that shows the ids you need.
- **Live server output on top.** Type any command and press **Send**, or tap one of your recent commands to run it again.

## Other changes

- **Steam lobby joins wait longer.** Joining through a Steam lobby keeps looking for up to 30 seconds, so a lobby that is still starting is found. Coodsz Host shows on Home whether the lobby is really up.
- **A note for non Steam copies.** The server log now says when two players join with the same Steam ID, which happens with non Steam copies of the game, and those players share one character. The launcher notes in its log and in **Save logs for help** when the game folder has files from a non Steam copy. Nothing is blocked.
- **The RBM box tells the truth.** RBM runs in each player's own game, not on the Coop server, so the server tool no longer writes RBM settings on Start and its RBM box is text only.
- **The NEW badge on Keep RBM coop friendly** now clears however you tick the box.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
