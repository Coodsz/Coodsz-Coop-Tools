## RBM wording and a new Console page

- **The RBM text tells the truth.** RBM runs in each player's own game, not on the Coop server. The client launcher no longer says Match the server; everyone in your group should pick the same RBM settings so battles feel the same. The server tool no longer writes RBM settings on Start, and its RBM box is text only.
- **A new Console page in the server tool.** Every Coop command in one list with categories and search, a How to use guide for each, **Use example** to fill in the boxes, and **Find ids** to list the ids you need. Live server output stays on top.
- **Steam lobby joins wait longer.** Joining through a Steam lobby keeps looking for up to 30 seconds, so a lobby that is still starting is found.
- **A note for non Steam copies.** The server log says when two players join with the same Steam ID, which happens with non Steam copies of the game. The launcher notes non Steam game files in its log and in Save logs for help. Nothing is blocked.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
