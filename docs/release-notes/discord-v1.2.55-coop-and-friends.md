# Discord announcement, Coop and Friends v1.2.55

Paste the text inside the block as one message. It stays under 2000 characters, has no colons and no hyphens between words.

```
**Coodsz Coop and Friends v1.2.55 is out**

This one is for everyone playing with RBM. Click Install update in the tool and you get it.

**RBM runs in your own game, not on the server**
Turns out the Coop server never runs RBM's code. Only RBM's items and troops load there. RBM's campaign rules run in each player's own game, so the settings on your PC are the ones that count.

**Connect keeps RBM coop friendly**
RBM has a setting where lords buy better gear every time they walk into a town. In coop that empties the town markets. When RBM is in your setup, Connect now turns that one setting off in your own RBM settings before the game starts. Nothing else in your RBM file changes, a backup is kept the first time, and the log tells you what it did. If you want your own value, untick the new Keep RBM coop friendly box under Connect.

**RBM settings card in Coodsz Host**
When RBM is in your setup, the Settings page has a card with RBM's parts and main campaign options, each with a short note on what it does. It edits the RBM file on that PC, so it is the host's own game. There is a Coop friendly button too.

**Start server leaves RBM alone now**
Since the server never reads RBM's settings, Start server no longer writes them.

Everything new is translated into all six languages. Let me know in this thread if anything acts up.
```
