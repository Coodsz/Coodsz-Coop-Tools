### What is new in v1.1.9

**Notices from Coodsz.** The tools can now show a notice from Coodsz at the top, in your language, for example while he is on vacation. A crash report bar or a reply to your report still shows first. **Dismiss** hides the notice until its words change.

**New setup starts again.** A setup made with **New setup** no longer refuses to start with **AD1259 - Coop Compatibility v1.1.0** missing. **Start server** now adds that module itself, and a new setup starts on the AD1259 map. If the module still can't be added, the message says it comes with this tool and to start again, instead of sending you to the Workshop. This came from AD1259 crash report #20.

**Download Coop server.** The Server Tool has a new **Download Coop server** button under **Advanced: server folder** on the **Settings** page. It opens Coop's dedicated server download (about 4.5 GB) in your browser, using the link on Coop's latest release. If that link can't be read, it opens Coop's release page instead. The server download is linked at the bottom of the release notes there, not under Assets. Unzip the download to a short folder like `C:\CoopServer`, then click **Set server folder**. When the server is not found, the message names this button and opens that group for you.

**A warning when the server's Coop is older.** When the game's Modules folder has a newer Coop than the server runs, the **Mods** page now says so under **Active Coop**, with **Download Coop server** and **Set server folder** buttons. Thanks to Maylay for the report.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.9.zip` and copy each program over the old one.

New text is translated into all six languages.
