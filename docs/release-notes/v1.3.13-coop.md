### What is new in v1.3.13

**Server Tool, My Little Warband recruits.** Players can now recruit their own My Little Warband troops in Coop. Before, the server turned every one of them down. The server and every player need CoopModPatch and My Little Warband. Gold is charged at the normal troop's price, not the price the recruit screen shows. Recruit xp from perks like Famous Commander moves with the troop.

**Server Tool, Copy setup tip.** The tip on the **Copy setup** button no longer says it copies the save and the map. It copies the mods, ports and MCM. Pick a save and a map for the new setup after.

The Client Launcher only got a new version number.

![The Coodsz Coop download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-Coop-and-Friends/main/images/Coodsz-Coop-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Coop-Tools-v1.3.13.zip` and copy each program over the old one.

New text is translated into all six languages.
