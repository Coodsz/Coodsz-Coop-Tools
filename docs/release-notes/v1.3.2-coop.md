### What is new in v1.3.2

**Find Bannerlord.** When a tool can't find Bannerlord, the new **Find Bannerlord** button lets you pick the game folder yourself. The tool remembers it.

**Answers to your reports show in the tool.** When Coodsz answers a report you sent, the answer now shows up right in the tool, so you don't have to wait for it in Discord. **My reports** next to **Send my logs** keeps your sent reports and every answer, with a search. If a fix did not help, click **Still not working? Ask Coodsz on Discord**. It opens the Coop Discord and copies a short message with your report code.

**A campaign that didn't load is never saved.** When a campaign fails to load, the Server Tool no longer saves over your save. **Save game**, **Stop**, **Restart**, backups and the automatic restart leave it as it was.

**Links no longer close the tools.** Steam Workshop and web links that Windows can't open now show a message instead of closing the tool.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Coop-Tools-v1.3.2.zip` and copy each program over the old one.

New text is translated into all six languages.
