### What is new in v0.1.2

**Server Tool, Console page.** The output box is taller and easier to read.

**Server Tool, commands.** A command still waiting in the Server Tool when the server restarts is now dropped instead of going to the new run. When the console is slow, the tool says the command may still arrive instead of saying it was sent.

**Mod settings for players.** Players already on the server now get the mod settings you change, even when someone joins right after the change. Before, they could keep the old value.

**Client Launcher, Connect.** A saved join password that ends in a line break is now hidden in the Activity box too, like any other join password.

**Server Tool, player list.** When the server log cuts off a players line, the player list now keeps the players it shows instead of going empty.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Realm-of-Thrones-Tools-v0.1.2.zip` and copy each program over the old one.

New text is translated into all nine languages.

The full steps are in README.-.Instructions.txt on this page: https://github.com/Coodsz/Coodsz-RealmOfThrones/releases/latest
