## A new AD1259 world starts with the whole pack again

**For hosts: the AD1259 set is always on when the server starts.** An extra campaign map inside SandBox (fixed in v1.0.29) also made the server tool turn off RBM, the armouries, the OpenSource and Templar mods, SettlementIconRedesign and the AD1259 coop compat module. A new AD1259 world then started with only 10 mods and could crash a few minutes after SERVING. Start server now turns the whole AD1259 set back on and says which mods it turned on.

**Safer updates.** Install update now checks that the download really comes from the Coodsz GitHub page and matches the release before it replaces any file. If a check fails, your old files stay as they are.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

AD1259 coop fixes by SkyApolo, bundled with permission. Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans and settings. See THIRD-PARTY-NOTICES.md in the zip.
