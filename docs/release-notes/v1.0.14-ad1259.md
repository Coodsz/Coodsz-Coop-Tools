## Keep RBM coop friendly

- **RBM's campaign rules run in each player's own game, not on the Coop server.** RBM's code does not run on the dedicated server, so the setting that matters for coop has to be right on every player's PC.
- **Connect in the AD1259 client launcher now also turns off RBM's Lords buy equipment** in your own RBM settings, together with the four RBM parts it already wrote. That setting makes lords buy up the gear in every town they enter, which empties the town markets in coop. Only that value changes, a config.xml.bak is kept the first time, and the log says what was changed.
- **Keep RBM coop friendly** is a new check box under the RBM parts, on by default. Untick it to keep your own setting.

The AD1259 server tool is unchanged apart from the version number. New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
