### What is new in v1.1.3

**The game keeps running.** After **Resume game**, the game keeps running until you press **Pause game**. To stop Coop pausing at all, turn **Auto pause** off on **Settings**.

**Antivirus help.** When a file the tool put in place goes missing later, the tool now says your antivirus most likely removed it and how to get it back, instead of only saying it was not found. The new **Fix antivirus** button lists the folders your antivirus should skip and opens Windows Security. It changes nothing on your PC by itself.

**Safer updates.** **Install update** is safer. The tool updates itself without a hidden PowerShell script, and when an update fails it puts the old version back so the tool still starts.

**Crash stack in crash reports.** When the game or the server crashes and Windows kept a crash dump, the crash report now adds a short text of the crash stack, read on your PC. The dump itself is only sent when you tick it.

**Save backups.** Save backups now work for a campaign that lost its .json file or its .sav, and putting a backup back over a missing save can always be undone. After you import a single player save, the server tool reminds you that only Sandbox campaigns run on a Coop server.

**Donate.** The new **Donate** button next to **What's new** lists Coodsz's Linktree with Patreon and PayPal, and Buy Me a Coffee under it. The tools stay free either way.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.3.zip` and copy each program over the old one.

New text is translated into all six languages.
