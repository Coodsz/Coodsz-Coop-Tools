## The first Coodsz Burning Empires tools

This is the first release. The live tests passed. They covered campaign names with Ü, Burning Empires population across a server restart, siege wall assaults, the Government tab, armor crafting greyout, travel, tournaments, raids, recruiting, and the save and backup flows. Expect some rough edges and please report them.

**One zip, two programs.** `Coodsz-Burning-Empires-Tools-v1.0.0.zip` holds **Coodsz Burning Empires Server Tool** and **Coodsz Burning Empires Client Launcher** and nothing else. The modules they need are inside each program, and they carry their own .NET, so there is nothing else to install.

![The Coodsz Burning Empires download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-BurningEmpires/main/images/Coodsz-BurningEmpires-new-download.png)

**Own icons.** The Server Tool and the Client Launcher each have their own orange Coodsz banner icon, and the Client Launcher's is a lighter shade, so you can tell them apart in the taskbar.

**For hosts.** Coodsz Burning Empires Server Tool runs a Burning Empires 2.0.2 Coop server. Click **Prepare server** once, then type a name and click **New campaign**, and the server starts a fresh Burning Empires world by itself. You can also host a single player Burning Empires save. **Install or repair Burning Empires** puts in the main file and then the hotfix from your Nexus download, and it never deletes your Burning Empires save data.

**For players.** Coodsz Burning Empires Client Launcher gets your game ready and joins the server. It uses one locked setup called Burning Empires, which loads the whole Burning Empires core with Elephants. It checks Harmony, ButterLib and UIExtenderEx from the Steam Workshop and MCM v5.12.3 or newer from Nexus Mods (the tools never download MCM), and the join check compares them with the host before the game starts.

**The compat patch.** Burning Empires Coop Compat 1.0.0 comes with both tools. Burning Empires was built for one player, so the patch makes the server the boss.
- The server runs Burning Empires and decides populations, religions, wanderers, bandits, champions and recruits.
- A new server starts a fresh Burning Empires campaign on its own.
- Things that only changed your own PC are greyed out, like settlement rename, moving population by hand and starting armor crafting.
- Features that cannot work yet are switched off, like champion duels, Burning Empires quests, the wonder stash and temple conversion.
- Nobody rides an elephant in a tournament, and elephant armor is never a prize.
- Single player is not changed.

**Known limits**
- Windows only. Linux hosted servers cannot run Burning Empires.
- The War Sails variant and the Historical campaign start are not supported.
- The first time you start the server, Windows may ask about the firewall. Click **Allow**.

**Known issues**
- On Coop 0.1.6, a hideout fight where your hero is knocked down never ends. This is a Coop bug, and a Coop fix is on the way.
- On Coop 0.1.6, accepting some quests can freeze the dialog. This is a Coop bug too. Coop's development version replaced that quest system.
- The campaign map ground can look black on some PCs. Burning Empires is missing a terrain shader cache file, and it happens in single player without Coop too. The Burning Empires author is looking into it.
- The Burning Empires population on your PC is a snapshot from when you join. It updates when you rejoin.

You need Bannerlord 1.4.8 and Bannerlord Coop 0.1.6 from the Steam Workshop. Burning Empires 2.0.2 comes from Nexus Mods (mods/7750).
