### What is new in v1.1.17

**Server Tool, host rules.** The Server Tool now puts Coodsz Server Tools on the server at every Start server, like the Coop Server Tool does. Players don't need it.
- The game pauses while a player joins and goes back to your speed when they are on the map. On by default. If you press **Pause game** or **Resume game** while it is pausing or resuming for a player, your choice waits for that to finish (up to about 15 seconds), and the join pause never undoes it. When the Coop server lets time run again after a player joins, the tool pauses it again if you had pressed **Pause game**.
- Offline players gain no skill XP until they come back. On by default.
- **Advanced: server rules** on the **Settings** page has these two switches, who may use coop.unstuck, and **Protect player kingdoms from AI wars**. Pick **Always** to protect player kingdoms while their players are online too.
- **Max clans per kingdom** and the **PvP rules** are on the **Settings** page too. Both are off until you set them. The AD1259 and Coop Server Tools on one PC share these settings, so anything you already set in the Coop Server Tool (these two and the kingdom choice) applies on the AD1259 server too.

**Server Tool, MCM settings for players.** Players who join with the AD1259 Client Launcher use your MCM settings while they play, so every PC runs the mods the same way. Their own files never change. You can look at and change what they get under **Advanced: mod settings for players** on the **Settings** page.

**Both tools, the Coop nightly.** The AD1259 tools never take the Coop nightly. When they find it, they now say so and how to go back to Coop 0.1.7 from the Steam Workshop, instead of telling you to update the tools.
- Client Launcher: the Coop row says where the nightly is and **Connect** stays off. A nightly in the game's Modules folder: move that Coop folder out of Modules. Nightly files in the Workshop Coop: in Steam, unsubscribe from Bannerlord Coop and subscribe again.
- Server Tool: **Start server** stops before it copies any mod when the server has the Coop nightly, and says what to do for that server. A server folder you picked with **Set server folder**: click **Use the Steam server** on the **Mods** page, then start again (if that button is not there, get Coop 0.1.7 from the Steam Workshop first). The Steam Workshop server: in Steam, unsubscribe from Bannerlord Coop and subscribe again. A server in the game's Modules folder: move that Coop folder out of Modules. A Bannerlord newer than 1.4.8 on your PC is still only a warning, since the server runs its own 1.4.8.

**Server Tool, Console page.** On a small window the **Console** page now keeps several lines of server output in view. The command list below gets smaller instead.

**Server Tool, fixes.**
- **Stop server** and **Restart** no longer hang when the server stops answering. When the server's console stops taking commands, the tool now ends the server within the usual 2 minute wait for the save on stop, instead of waiting forever.
- A command left waiting when the tool was closed no longer runs when the server starts again.
- Text you send to the server, like a say message on the **Console** page, now keeps letters like ü, ñ, Cyrillic or Chinese. Before, players saw boxes instead.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.17.zip` and copy each program over the old one.

New text is translated into all nine languages.
