## Automatic restart works, and crash reports can carry the crash dump

**For hosts: Automatic restart works.** Tick **Automatic restart** on the Settings page of Coodsz Host and set the hours in **Restart interval**. While Coodsz Host is open, it saves the running campaign, stops the server and starts the same save again after that many hours. Players get a warning 30 seconds before. The Coop server never did this by itself, even with the box ticked. On an older config the box starts unticked, so tick it, set the hours and press **Save settings** to turn it on.

**For hosts: Restart no longer freezes Coodsz Host.** Before, the window could go black after the server stopped, and the server did not start again.

**MCM comes from Nexus Mods.** The official Steam Workshop item for Mod Configuration Menu (MCM) was removed, and the copies left on the Workshop can be old builds the server refuses. The tools no longer ask Steam for it and point you to Nexus Mods instead. **Start server** copies a newer MCM from the game's Modules folder onto the server, and an older Workshop copy never replaces a newer one there.

**Crash reports can add the crash dump.** **Send crash report**, **Send server crash report** and **Send my logs** can now add the newest crash dump, so Coodsz can see where the game or server crashed. A server crash report finds the server's own crash dump too. The **Add the crash dump** box shows only when a dump was found and starts ticked. A crash dump is a snapshot of memory and is not cleaned: it can hold your Windows user name, Steam id, the join password, player addresses and anything the game had open. Only Coodsz can open it. Untick the box to leave it out.

**For hosts: player reports on the Modules page.** Each mod row in Coodsz Host now shows what players reported, with a **Report** link, like the client launchers.

**For hosts: safer save backups.** Backups now wait until the server has finished writing the save. Before, a backup made while the server was still saving could fail to load later. A save with letters like Ü or İ in its name now gets backed up too.

**For hosts: clearer crash and status messages.**
- The server crash bar takes its crash line from this run only, and a warning that something may still crash is no longer named as the cause.
- Crash reports now recognise when Steam closed the server.
- The logs Coodsz Host sends read the server's own engine log, not a game open on the same PC.
- A join password that is also a common word no longer mangles mod ids like Bannerlord.Harmony in the logs.
- When you answer No to adding mods to a campaign, the status box says what happened, which mods, and what to do, on three short lines.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
