### What is new in v1.1.12

**New campaigns on Coop 0.1.7.** A new AD1259 campaign on Coop 0.1.7 no longer stops the server. Coop picks a companion from a list that AD1259 leaves empty for some types, and the server stopped on that empty list. The fixed AD1259 - Coop Compatibility module v1.1.1 now picks from a type that has companions, or skips the companion that time. **Start server** puts v1.1.1 in place of v1.1.0 on its own, so there is nothing to do but update and start.

AD1259 - Coop Compatibility is by SkyApolo, bundled with permission.

The Client Launcher only got a new version number.

![The Coodsz AD1259 download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-AD1259/main/images/Coodsz-AD1259-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.12.zip` and copy each program over the old one.

New text is translated into all six languages.
