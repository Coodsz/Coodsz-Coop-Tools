### What is new in v1.1.13

**Client Launcher, crash on the AD1259 map.** Some players crashed on the campaign map every time they joined, because Bannerlord couldn't remove its old AD1259 map shader files. The game should no longer crash there. When you click **Connect** and the game's logs show such files, the Client Launcher moves them aside and the game builds new ones. If Windows won't let it, most likely because the game once ran as administrator, the Client Launcher asks once and Windows asks for permission. Say No and Connect goes on as before.

The Server Tool only got a new version number.

![The Coodsz AD1259 download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-AD1259/main/images/Coodsz-AD1259-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.13.zip` and copy each program over the old one.

New text is translated into all six languages.
