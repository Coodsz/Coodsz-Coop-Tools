## Improved Garrisons problems can be checked

**Send my logs in Coodsz Host now also sends the CoopModPatch logs and the Improved Garrisons settings.** The server log pack carries CoopModPatch's server and client logs and the Improved Garrisons settings file (ig-settings.txt), so a problem with Improved Garrisons in co op can be looked at. They are cleaned like the other logs.

## One more known crash cause

**A graphics driver error while the map terrain loads.** When the game crashes because Bannerlord could not create a texture on the graphics card while the map terrain loaded, the crash screen now says so. It tells you to update your graphics driver from the NVIDIA, AMD or Intel website and to try another Terrain quality in the game's video settings. It is not Coop or the Coodsz tools, so you don't need to send a report and Send becomes a small link.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
