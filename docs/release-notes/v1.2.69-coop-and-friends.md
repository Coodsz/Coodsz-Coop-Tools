## Improved Garrisons works properly on the dedicated server

**Town settings stay after a server restart.** Before, Improved Garrisons deleted the players' town settings on the dedicated server when it started, and CoopModPatch then saved the empty list, so templates, recruitment and training were lost. Now they are kept.

**Settings follow the clan.** When a town goes to another member of the same clan, its Improved Garrisons settings stay. When it goes to another clan, they are reset, so the new owner starts clean.

**Only the owner can change a town.** Before, any player could change the Improved Garrisons settings of any town. Now only the town's owner can. Copying settings to other garrisons only reaches the owner's own towns and castles.

Coodsz Host adds the new server module (DedicatedServer.IGCoopCompat) by itself when Improved Garrisons is on. Players install nothing.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
