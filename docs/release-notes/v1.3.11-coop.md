### What is new in v1.3.11

**Client Launcher, crash on the campaign map.** The game should no longer crash on the campaign map because of old map shader files Bannerlord can't remove. When you click **Connect** and the game's logs show such files, the Client Launcher moves them aside and the game builds new ones. If Windows won't let it, most likely because the game once ran as administrator, the Client Launcher asks once and Windows asks for permission. Say No and Connect goes on as before.

The Server Tool only got a new version number.

![The Coodsz Coop download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-Coop-and-Friends/main/images/Coodsz-Coop-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Coop-Tools-v1.3.11.zip` and copy each program over the old one.

New text is translated into all six languages.
