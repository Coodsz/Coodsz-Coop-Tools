### What is new in v1.1.38

**CoopModPatch works with Improved Garrisons on the server, for real this time.** Improved Garrisons only comes with the game's client files, so v1.1.37 had no server DLL to switch on. Start server now makes the server copy from the client files when CoopModPatch is in your setup. Players no longer see "IG: no response from the server to the configuration request".

**Save logs for help cleans crash reports.** The newest crash report zip is unpacked and cleaned like the other logs, so your join password and addresses are taken out. A rar crash report can't be cleaned, so it is left out with a note saying where to find it.

**Steam lobby joins wait longer.** Joining through a Steam lobby keeps looking for up to 30 seconds, so a lobby that is still starting is found.

**A note for non Steam copies.** The server tool's activity log says when two players join with the same Steam ID, which happens with non Steam copies of the game. The client launcher notes in its log and in Save logs for help when the game folder has files from a non Steam copy. Nothing is blocked.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
