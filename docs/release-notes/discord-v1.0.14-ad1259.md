**Coodsz AD1259 tools v1.0.14 are out**

A small RBM update for players. Click Install update in the client launcher.

**RBM runs in your own game, not on the server**
The Coop server never runs RBM's code. RBM's campaign rules run in each player's own game, so the settings on your PC are the ones that count.

**Connect keeps RBM coop friendly**
RBM has a setting where lords buy better gear every time they walk into a town. In coop that empties the town markets. Connect now turns that one setting off in your own RBM settings, together with the four RBM parts it already set. Nothing else in your RBM file changes, a backup is kept the first time, and the log tells you what it did. If you want your own value, untick the new Keep RBM coop friendly box under the RBM parts.

The server tool only got a new version number. AD1259 coop fixes are by SkyApolo, bundled with permission. Let me know in this thread if anything acts up.
