### What is new in v1.1.35

**Save logs for help packs what support needs.** The client zip now also has TAOM's own stall reports (the taom_crash zips from the last 3 days, unpacked with their text cleaned), the logs of a TAOM server on the same PC (Coop_server.log, coop-server and host-console logs, and the server's taom_debug logs), and every log of each game and server session (the full engine log, its errors log and its watchdog log). Before, the errors logs could push the full logs out, and a server's full log was left behind. Sizes are capped, so the zip stays small enough to send. The server tool's Save all logs to one zip adds the watchdog log of each server session too.

**The join password stays private.** The game's command line in the engine and watchdog logs carried the join password. Both log zips now take it out, like the addresses and Steam IDs.

**Low memory warning.** A yellow line under Connect warns when your PC is low on memory, or when a dedicated server runs on the same PC with less than 24 GB. TAOM froze for a player at 97% memory on a 16 GB laptop that also hosted the server. Close heavy apps such as browsers, run the server on another PC if you can, and let Windows manage the page file size. Connect still works. The server tool writes the same kind of warning in its log at Start server.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

## Coodsz TAOM tools v1.1.35 for TAOM-Coop 0.3.25

Works with Bannerlord 1.4.8, TAOM 2.0.29.5 (all four modules), Workshop Coop 0.1.6 and TAOM.CoopCompat 0.3.25. TAOM 2.0.27 campaigns do not load on 2.0.29.5, so start a new campaign.

### Players
1. Install the .NET 8 Desktop Runtime x64 from https://dotnet.microsoft.com/download/dotnet/8.0
2. Download Coodsz-TAOM-Client-Launcher-v1.1.35.zip and unzip it.
3. Download TAOM-Coop-v0.3.25-CompatOnly-CLIENT-PLAYTEST-1675bea7-a2ac41c2-r2.zip and leave it zipped.
4. Subscribe to Bannerlord Coop on the Steam Workshop (3770450698) so you get 0.1.6.
5. Download TAOM 2.0.29.5 and leave it zipped, from https://www.moddb.com/mods/tales-from-the-age-of-men/downloads/taom-public-2-0-29-5
6. Open the launcher and click Check mods, Install or repair TAOM, then More tools and Use Workshop Coop 0.1.6. Pick the same mod setup as the host, then Connect (Direct, with the host IP and UDP 4200).

### Host
Do the player steps, then download Coodsz-Dedicated-TAOM-Server-Tool-v1.1.35.zip and TAOM-Coop-v0.3.25-CompatOnly-HOST-OPERATOR-1675bea7-a2ac41c2-r2.zip (leave it zipped). Make a new 2.0.29.5 campaign in single player, pick it, then Prepare server, Start server, and click I accept on the Coop server terms. Give players your IP and UDP 4200, or use Copy invite. Steam lobby is optional (tick Advertise through Steam).

The full instructions are in README - Instructions.txt below.
Already have the tools? Click Install update, or unzip over your old folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events and backups. See THIRD-PARTY-NOTICES.md in the zip.
