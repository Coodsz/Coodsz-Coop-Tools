### What is new in v1.1.8

**A new look.** Both tools have a sidebar with their pages. The Server Tool opens on the new **Dashboard**, with **Saves**, **Mods**, **Settings**, **Logs** and the other pages under it. The Client Launcher opens on **Play**, with **Mods**, **Logs and help** and **Settings**. A picture sits behind the pages, and only one notice shows at a time.

**The mod list is locked while the server runs.** On the Server Tool's **Mods** page the switches, the move arrows and **Save module config** are off while the server runs, so the server keeps the mods the players joined with. A setup you pick meanwhile is used at the next **Start server**.

**Dashboard cards.** The Server Tool's **Dashboard** has a **Mods** card with how many mods are on, and a **Made for** card with the Bannerlord, AD1259, RBM and Coop versions of the AD1259 pack, with a green tick when the server matches. The Client Launcher's **Play** page has the **Made for** card too.

**Clearer chip words.** Mod rows say **Always on** instead of Required and **Wrong version** instead of Version, and SkyApolo's bundled AD1259 modules get a **Bundled** chip.

**The crash report bar waits.** When the Server Tool tries a load crash again by itself, the **Send server crash report** bar waits for that try and shows only if it crashes too.

**Smaller fixes.** The AD1259 community mod list now covers Coop v0.1.7 as well as v0.1.6. **My reports** keeps checking for answers after the PC clock was set back.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.8.zip` and copy each program over the old one.

New text is translated into all six languages.
