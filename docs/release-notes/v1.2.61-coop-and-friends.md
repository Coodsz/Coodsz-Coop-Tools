## Fixes

**Joining no longer gets stuck on Final Synchronization.** When a few parties went missing while a player's game loaded the campaign, Coop refused the join and retried until the player sat on **Final Synchronization** forever. The client fix that comes with the tools now puts back the parties the server says are there, and writes each one to `Documents\Mount and Blade II Bannerlord\Client Diagnostics\CoodszJoinPassword.log`.

**The server no longer stalls behind the Coodsz Host window.** Coodsz Host waited for its window to draw every server line before reading the next one. On a slower PC a burst of log lines (a modded character can print thousands) held the server long enough to time out a player's character on join. Lines are now read right away and drawn in batches.

**The update bar fits a smaller window.** In a narrow window the update bar used to scroll off to the side with its **Install update** button. It now stays at the top.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
