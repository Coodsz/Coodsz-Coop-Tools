## Big battles with Limitless

**Battle size goes up to 10000.** With Limitless and Limitless Coop Compat in the server's mods, the Battle size slider on the Settings page of Coodsz Host goes up to 10000 soldiers on the field, both sides together. Armies bigger than that still fight, the extra troops come in as reinforcements.

Every player's PC shows the whole battle, so the Settings page helps you pick a size. It shows how heavy the battle is (Smooth, Big battle or Epic), about how much RAM each player needs, and a suggested size for your PC.

- When the server has Limitless but not Limitless Coop Compat, the Settings page says so, and **Add Limitless Coop Compat** turns it on for you with one click. Players need it too.
- With both on, a Battle size you save while the server runs applies from the next battle.
- Adding Limitless Coop Compat to a running campaign keeps the save usable.
- Joining a big battles server on a PC with less than 16 GB of RAM shows a short warning in the launcher. It never stops you from joining.

Without Limitless nothing changes, and Battle size stays at 200 to 1000.

## The crash screen tells you what happened

**When the game or server crashes, the crash screen now says what happened and how to fix it.** The tools check the logs against a list of known crash causes before anything is sent. For a known cause that needs no report the screen says No need to report this, with the fix, and Send becomes a small link. For a known Coop bug it still asks for your logs, because every report helps. For anything else Send stays big, and sending it helps Coodsz find the cause.

## Fixes

**Changing the mod load order no longer hides your campaign save.** Bannerlord does not check the order of a save's mods, so the server now opens the save and only notes in the log that the order changed. When a save really does not match the mods (one turned off, removed or a different version), Coodsz Host says so and what to do, instead of calling it a crash and running the save fixes.

**Servers no longer crash on mods that ship a raw Assets folder**, like Banner Fix, Raise your Banner and Raise your Torch. Every server start hides that folder in the server copy (renamed to Assets.off), and players keep theirs. If another mod's Assets folder crashes the server, Coodsz Host hides that one too and says the save is fine, so you just press Start server again.

**CoopModPatch's first setup stop is no longer shown as a crash.** CoopModPatch stops the server once on purpose after it copies its files. Coodsz Host now says Setup finished. Press Start server again.

**Using Diplomacy without Diplomacy Coop Compat now shows a warning.** Without it messengers and some buttons break the game in co op. Nothing is turned off or added for you.

**Exit code 1 with no error is explained.** When the server stops that way, Coodsz Host now says it was most likely closed from outside, for example by an antivirus, Task Manager or a script, and what to check. The crash report also adds the Windows event log entries around the crash.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
