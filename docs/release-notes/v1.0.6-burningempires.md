### What is new in v1.0.6

**Choose Coop server.** New **Choose Coop server** button in the Server Tool, for when the Workshop Coop server is missing or older. Pick the folder you unzipped Coop's v0.1.7 dedicated server package to, and **Prepare server** and **Start server** copy that server in. **Prepare server** now asks before it puts an older Coop over a newer one, and **Start server** keeps the newer Coop.

**Coop v0.1.7 installed by hand.** Coop v0.1.7 is out on Coop's GitHub release and on ModDB. It has to end up as `Modules\Coop`. The GitHub zip already holds a Coop folder, so unzip it into the game's Modules folder. The ModDB download has no Coop folder inside, so make a folder named Coop in Modules and unzip it into that. The game loads that copy before the Workshop Coop, so the Client Launcher keeps it when it is as new as the Workshop Coop or newer, and its Coop row says Modules or Workshop.

**Coop in the wrong folder.** The ModDB download has no Coop folder of its own, so it is easy to end up with the wrong layout. When Coop is in a folder with another name, has a second copy, sits inside another folder, was unzipped straight into Modules or is one folder too deep, **Check mods** says what to rename or move.

**Downloaded files unblocked.** Windows marks unzipped files as downloaded from the internet, and the game won't load a marked DLL. The Client Launcher now unblocks Coop's files on **Check mods** and before the game starts.

**Join errors.** When Coop v0.1.7 refuses a join over a missing or wrong mod, the tools explain it again. Coop v0.1.7 writes mod names in a new way.

**Smaller fix.** The Client Launcher no longer blames antivirus for a Coodsz add on that was never installed.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.6.zip` and copy each program over the old one.

New text is translated into all six languages.
