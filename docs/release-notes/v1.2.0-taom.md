### What is new in v1.2.0

**One zip, two programs.** The server tool is now called **Coodsz TAOM Server Tool** (it was Coodsz Dedicated TAOM Server Tool). The client launcher keeps its name, **Coodsz TAOM Client Launcher**. Both come in one zip, `Coodsz-TAOM-Tools-v1.2.0.zip`, with nothing else in it. The modules and bundled mods are inside each program.

![The new Coodsz TAOM download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-TAOM/main/images/Coodsz-TAOM-new-download.png)

**No .NET install needed.** The TAOM tools now carry their own .NET, so you no longer need to install the .NET Desktop Runtime.

**Fewer dead ends on the server.** When antivirus removes StoryMode.dll, MCMv5.dll or other module files from the server, Start server puts them back after checking each one, or names what is missing, and no longer treats it as a save that crashes on load. A save that is not a TAOM campaign is now refused with one plain message, and a busy tool says to wait instead of saying Bannerlord was not found.

**A new Advanced switch.** The server tool has a switch under Advanced, Heavy troops count more toward party size (TAOM troop weight). It's off by default, and greyed out when your TAOM server kit doesn't have the setting yet.

**Your settings move by themselves.** They now live in %LOCALAPPDATA%\Coodsz\TAOM. Each program copies them there from its old folder on its first start, so keep the old folder until then.

**New icons.** The Server Tool and the Client Launcher each have their own Coodsz banner icon, and the Client Launcher's is a lighter shade, so you can tell them apart in the taskbar.

### How to update

- **If you already have the tools,** click **Install update**. On its first start the server tool takes its new name, moves your Desktop, Start Menu and taskbar shortcuts to itself, and removes the old exe. If a shortcut can't be moved, the old exe stays and the next start tries again.
- **Updating by hand.** Close the tools, download `Coodsz-TAOM-Tools-v1.2.0.zip`, and copy each program into the folder where you already have that tool so it finds your settings. Choose Replace if Windows asks.
- **A new install.** Unzip `Coodsz-TAOM-Tools-v1.2.0.zip` into a folder of its own.

The two zips named Coodsz-Dedicated-TAOM-Server-Tool and Coodsz-TAOM-Client-Launcher are only there so older tools can update themselves. You don't need to download them.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages.
