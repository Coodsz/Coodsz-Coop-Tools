### What is new in v1.1.10

**Coop v0.1.7 is on the Steam Workshop.** Workshop item 3770450698 has had Coop v0.1.7 since October 30, so the tools no longer tell you to get it from Coop's GitHub release. When Coop is missing, the Client Launcher says to get it from the Steam Workshop, like before.

**Use the Workshop's dedicated server.** The Workshop item comes with its own dedicated server in its `DedicatedServer` folder, and that is the one to use. The Server Tool finds it by itself. **Download Coop server** under **Advanced: server folder** on the **Settings** page is still there for a server you unzip yourself and pick with **Set server folder**.

**Improved Garrisons on a new campaign.** **Start server** now copies `StoryMode.dll` from the game into a Coop 0.1.7 server that leaves it out. Improved Garrisons needs it on a new campaign. Thanks to Ruhan for the report.

![The Coodsz AD1259 download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-AD1259/main/images/Coodsz-AD1259-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.10.zip` and copy each program over the old one.

New text is translated into all six languages.
