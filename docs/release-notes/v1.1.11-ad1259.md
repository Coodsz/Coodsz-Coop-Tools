### What is new in v1.1.11

**The older Open Source set works too.** Both tools now also take Armory 1.18, Saddlery 1.8 and Weaponry 1.8 from Nexus Mods (the files named FOR v1.2.x), next to the 2.0 set. The AD1259 team recommends the older set for AD1259 1.4.6, since with 2.0 some gear can show missing textures. Either set works, but the host and every player must use the same one. The tools say which set you have and warn about a mix. The server gets the set the host's game loads.

**The server's own reason when it stops.** When the dedicated server stops itself with a FATAL line, the Server Tool now quotes that line. Before, it said the server was closed from outside.

**A game Coop in the server folder.** **Start server** now warns when a game (client) Coop was copied into the server's own `DedicatedServer\engine\Modules\Coop` folder. The server can't load that copy. To fix it, unsubscribe from Workshop item 3770450698 in Steam, subscribe again and wait for the download. Steam's Verify does not repair Workshop items. Nothing is moved for you.

**Use the Steam server.** When the server folder you picked with **Set server folder** has an older Coop than the Steam Workshop server, the **Mods** page says so under **Active Coop**. Click **Use the Steam server** to go back to the Workshop server. Your picked folder stays on disk. Stop the server first. The line shows only while the Workshop Coop is not newer than the Coop AD1259 needs.

**Map box.** When the AD1259 map files are missing on the server, the Server Tool's map box shows the map with "(map files missing on the server)" instead of staying blank.

**Client Launcher on Coop 0.1.7.** The status at the top no longer stays on Joining while you play. When Coop's client log stays empty, it says Game open instead. **Send my logs** also packs the newest three numbered Coop client logs that Coop 0.1.7 writes.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.11.zip` and copy each program over the old one.

New text is translated into all six languages.
