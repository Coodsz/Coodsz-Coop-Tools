### What is new in v1.2.6

**TAOM stays on Coop v0.1.6.** Coop v0.1.7 is out, but TAOM-Coop 0.3.25 is made for Coop v0.1.6, so the TAOM tools keep it. When a newer Coop is in the game's Modules folder, the Client Launcher says so and points you to **More tools**, **Use Workshop Coop 0.1.6**. That moves the newer copy out of Modules, kept, not deleted.

**A newer Workshop Coop.** When the Workshop Coop is newer than v0.1.6, the tools now say TAOM needs a tools update for it, instead of telling you to wait for Steam or verify Bannerlord.

**Where Coop comes from.** The Coop row in the mod list now says whether Coop comes from the game's Modules folder or the Steam Workshop.

**Smaller fix.** The Client Launcher no longer blames antivirus for a Coodsz add on that was never installed.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.6.zip` and copy each program over the old one.

New text is translated into all six languages.
