## Your join password stays out of the log zips

- **Save logs for help now takes your join password out of the logs.** Bannerlord writes its command line into its engine and watchdog logs. Coop and Friends hands the password to the game another way, but a game started with the password on its command line (the TAOM and AD1259 launchers do that) leaves it in those logs, and the log zip packs the engine logs of every game on this PC. The zip now replaces it with [password], in Coop and Friends and in Coodsz Host.
- **More places are cleaned.** A quoted password (two words in quotes) now goes as a whole, settings files in a crash report folder (.ini, .cfg) are cleaned like the other logs, and a zip inside a crash report folder is unpacked so its logs are cleaned too.
- **If you already sent a log zip to someone,** it may have your join password in it. Change the server password in Coodsz Host if that worries you.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
