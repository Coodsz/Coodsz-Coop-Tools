### What is new in v1.1.52

**Crash reports can add the crash dump.** **Send crash report**, **Send server crash report** and **Send my logs** can now add the newest crash dump, so Coodsz can see where the game or server crashed. A server crash report finds the server's own crash dump too. The **Add the crash dump** box shows only when a dump was found and starts ticked. A crash dump is a snapshot of memory and is not cleaned: it can hold your Windows user name, Steam id, the join password, player addresses and anything the game had open. Only Coodsz can open it. Untick the box to leave it out.

**Player reports on more mod rows.** Each mod row on the Modules page of the TAOM server tool now shows what players reported, with a **Report** link. In the TAOM client launcher, the TAOM core mod rows show player reports and the **Report** link too.

**For hosts: safer save backups.** Backups now wait until the server has finished writing the save. Before, a backup made while the server was still saving could fail to load later. A save with letters like Ü or İ in its name now gets backed up too, and the TAOM server tool reads the server window's text in the right code page, so those names no longer come out garbled.

**Clearer crash messages.**
- The server crash bar no longer names a warning that something may still crash as the cause.
- A join password that is also a common word no longer mangles mod ids like Bannerlord.Harmony in the logs.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
