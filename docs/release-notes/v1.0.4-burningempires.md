### What is new in v1.0.4

**My reports.** A red badge on **My reports** now counts the reports with a new answer from Coodsz. Each report shows its status (Looking into it, Answered, Solved or Fixed in a version), and the steps in Coodsz's reply show as a list.

**Did this fix it?** Under each answer you get two buttons. **Yes, it's fixed** tells Coodsz it worked. **No, still broken** opens a short form, and what you write, your new logs and a screenshot if you add one go to the same report.

![The Coodsz Burning Empires download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-BurningEmpires/main/images/Coodsz-BurningEmpires-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.4.zip` and copy each program over the old one.

New text is translated into all six languages.
