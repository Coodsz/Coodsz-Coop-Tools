### What is new in v1.1.51

**Connect now checks the server first.** With Direct, the TAOM client launcher asks the server for an answer before the game starts. If nobody answers within 5 seconds, or the address is your own PC, your router or your VPN, the launcher tells you and offers Steam lobby instead of sitting on Contacting the server forever. Pick **Use Steam lobby**, type your host's Steam name, then click **Connect**. **Connect anyway** is still there if you know the address is right.

**For hosts: Steam lobby when your internet shares its address.** Some internet providers share one address between many homes, so friends can not reach your server directly. When the TAOM server tool sees that, it turns Steam lobby on for you once, and Copy invite tells friends to join through Steam lobby. Copy invite never sends friends to Steam lobby while it is off: it offers to turn it on and restart the server first. If you turn Steam lobby off again, it stays off.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

**Connect asks to close a game that is still open.** If Bannerlord is still running, for example a game that froze in the background, Connect used to do nothing visible. Now the TAOM client launcher asks whether to close it and connect. No is the default, so a stray Enter does not throw away a game you are playing.

**A warning for a mod that is in two Workshop items.** Steam keeps old subscriptions, even after you reinstall the game. If you are subscribed to two Workshop items that carry the same mod, like an old second upload of Harmony, ButterLib or UIExtenderEx next to the official one, the game can load the wrong copy and crash at startup. The TAOM client launcher now names both items, says which one the game loaded and gives the link of the one to unsubscribe. If the game crashes at startup, that comes first in the crash message.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
