## A server with AD1259 no longer stops on an extra SandBox map

**For hosts: a server with a map mod no longer stops because of an extra map in SandBox.** Some dedicated servers have a second campaign map inside the SandBox module, left behind by an older tool version or a copied game folder. With a map mod like AD1259 the server then stopped before it loaded, with "Multiple active modules provide SceneObj\Main_map". Start server now finds that folder and offers to move it aside to DedicatedServer\removed-mods, where it can be put back. An automatic restart moves it by itself. If a start still fails with two maps, the tool says which folder to move instead of blaming a working mod.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
