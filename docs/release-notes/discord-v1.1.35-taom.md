# Discord announcement, Coodsz TAOM tools v1.1.35

Paste the text inside the block as one message. It stays under 2000 characters, has no colons and no hyphens between words.

```
**Coodsz TAOM tools v1.1.35 are out**

A support update. Click Install update in both tools.

**Better log zips**
Save logs for help now also packs the TAOM stall reports from the last few days, the logs of a TAOM server if you host on the same PC, and every log of each game and server session. So when you send me a zip after a freeze, I can actually see what happened on both sides.

**Your join password stays private**
The game command line in the logs had the join password in it. Both log zips now take it out, the same way they already hide addresses and Steam IDs.

**Low memory warning**
If your PC is almost out of memory, or you run the dedicated server on the same PC with less than 24 GB, a yellow line under Connect tells you. TAOM can freeze when Windows runs out of memory. Close heavy stuff like browsers, run the server on another PC if you can, and let Windows manage the page file. The server tool warns at Start server too.

Everything new is translated into all six languages. Tell me in this thread if anything breaks.
```
