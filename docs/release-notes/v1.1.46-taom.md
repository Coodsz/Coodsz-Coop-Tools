### What is new in v1.1.46

**The crash screen tells you what happened.** The TAOM client launcher and server tool now get the crash check the Coop and Friends tools have. When the game or server crashes, the tools check the logs against a list of known crash causes before anything is sent. For a known cause that needs no report the screen says No need to report this, with the fix, and Send becomes a small link. For anything else Send stays big, and sending it helps Coodsz find the cause.

Two new known causes come with it:

- **A graphics driver error while the map terrain loads.** The crash screen says to update your graphics driver from the NVIDIA, AMD or Intel website and to try another Terrain quality. It is not Coop or TAOM, so you don't need to send a report.
- **The TAOM.CoopCompat startup check.** See below.

**A stop by TAOM.CoopCompat's startup check is no load crash.** TAOM.CoopCompat checks the server before it lets players in, and when that check fails it stops the server on purpose. The save was not loaded yet, so the server tool now says your save is fine and to press **Start server** again. It no longer runs the save fixes or the load retry for it. If it stops the same way twice in a row, the crash bar comes back so you can send the report.

**Improved Garrisons problems can be checked.** **Send my logs** in the server tool now also sends the CoopModPatch server and client logs and the Improved Garrisons settings file (ig-settings.txt). They are cleaned like the other logs.

**Smaller fixes**

- Joining a big battles server on a PC with less than 16 GB of RAM shows a short warning in the client launcher. It never stops you from joining.
- **Save settings** also works with an empty Autosave minutes box, and a box left empty shows the kept value again.
- Popup windows now always open inside the screen, so Send and every other button can be reached.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
