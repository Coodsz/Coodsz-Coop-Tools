### What is new in v1.2.8

**Notices from Coodsz.** The tools can now show a notice from Coodsz at the top, in your language, for example while he is on vacation. A crash report bar or a reply to your report still shows first. **Dismiss** hides the notice until its words change.

**The zip search no longer stops at a broken folder.** When the tools look for the TAOM-Coop CompatOnly zips on this PC, they now skip a folder Windows can't read, like a damaged folder under `AppData\Local`, and keep looking. Before, the search stopped with a Windows error. Thanks to SinGreed for the report.

![The Coodsz TAOM download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-TAOM/main/images/Coodsz-TAOM-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.8.zip` and copy each program over the old one.

New text is translated into all six languages.
