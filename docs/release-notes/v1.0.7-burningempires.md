### What is new in v1.0.7

**A new look.** Both tools have a sidebar with their pages. The Server Tool opens on the new **Dashboard**, with **Saves**, **Mods**, **Settings**, **Cheats**, **Console**, **Logs** and **Guides** under it. The Client Launcher opens on **Play**, with **Mods**, **Logs and help**, **Settings** and **Guides**. A picture sits behind the pages, and only one notice shows at a time.

**The hosted save no longer switches without a word.** The Server Tool now asks before **Name server copy** copies, or **Start server** hosts, a save that is earlier in the campaign than the one the server last ran. The save list shows each save's campaign day.

**Locked while the server runs.** On the **Mods** page the switches, the move and remove buttons, **Save mods** and **Install mods** are off while the server runs. **Prepare server** now says to stop the server first instead of changing its files.

**Dashboard cards.** The Server Tool's **Dashboard** has a **Mods** card with how many mods are on, and a **Made for** card with the Bannerlord and Burning Empires versions these tools are made for and the Coop version the server has, with a green tick when the server matches. The Client Launcher's **Play** page has the **Made for** card too.

**The crash report bar waits.** When the Server Tool tries a load crash again by itself, the **Send server crash report** bar waits for that try and shows only if it crashes too.

**Smaller fixes.** The mod list chips have clearer words, **Always on** instead of Required and **Wrong version** instead of Version. The Burning Empires community mod list, and the copy built into the tools, are now for Coop v0.1.7. **My reports** keeps checking for answers after the PC clock was set back.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.7.zip` and copy each program over the old one.

New text is translated into all six languages.
