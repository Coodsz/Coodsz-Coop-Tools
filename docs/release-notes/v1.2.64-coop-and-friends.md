## Fixes

**Players who join no longer attack a lord when they try to enlist in TAOM.** TAOM's enlisting only works for the server right now, so a player who joined and swore the oath to a lord ended up in a battle against him. When TAOM is in the game, the client fix that comes with the tools now greys out **I wish to enlist under your command** for joining players, with a note that enlisting is not supported in co op yet. If the oath still gets sworn somehow, the player just leaves the lord instead of fighting him. Without TAOM nothing changes.

**Settings sync checks less often for a mod you don't have.** When the host shares the settings of a mod that is not on your PC, the game used to look for it every 5 seconds for the whole session and rebuild every mod's settings menu each time, which could make the game stutter. Now it only checks that often while a mod you do have is still setting itself up. For a mod you don't have it waits longer between checks, up to once a minute, and gives up after 10 minutes.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
