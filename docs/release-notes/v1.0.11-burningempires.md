### What is new in v1.0.11

**Client Launcher, joining your campaign.** Some players crashed every time they joined their Burning Empires campaign, while the game checked the campaign map. Joining should no longer crash there. When one party, army, battle or settlement on the map is broken, the game now skips it, writes it to `Documents\Mount and Blade II Bannerlord\Client Diagnostics\CoodszJoinPassword.log` and keeps loading. If the game still crashes when you join, click **Send my logs** in the Client Launcher again.

**Server Tool, Start server.** Every start used to add Launcher Cheats and Launcher Battle Size to the server's `DedicatedServer.Windows` module again, so the same add on could load many times. Start server now keeps one of each, removes the repeats and says how many went. It backs up the file first as `SubModule.xml.coodsz-original`.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.11.zip` and copy each program over the old one.

New text is translated into all six languages.
