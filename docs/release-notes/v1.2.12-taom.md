### What is new in v1.2.12

**Client Launcher, joining while Steam has Coop 0.1.7.** TAOM players can join again while Steam has Coop v0.1.7. Get `BannerlordCoop-v0.1.6.zip` from Coop's GitHub v0.1.6 release and unzip it into the game's Modules folder, so `SubModule.xml` sits in `Modules\Coop`. That Coop loads before the Workshop one. **Get Coop 0.1.6** on the **Play** page opens that release, and it only shows when you need it. If Coop 0.1.6 is already in the game's Modules folder, the Client Launcher leaves it there.

**Server Tool.** The Server Tool no longer says TAOM waits for a new TAOM.CoopCompat. Hosting still needs a Coop 0.1.6 dedicated server, and the Server Tool says where to get it. The guides and the instructions say the same. **Choose Coop 0.1.6 server** now says when the picked folder has the Coop 0.1.6 client (`BannerlordCoop-v0.1.6.zip`) instead of the dedicated server, and it never stays quiet after a pick. It now shows its result right under the button on the Saves page too.

**Server Tool, a frozen map when the server's own hero is a prisoner.** Save Rescue now keeps the map moving when a save has the server's own hero, the one nobody plays, as a prisoner (seen with TAOM). Before, the server kept opening a captivity menu and every party stood still. The hero stays a prisoner, and nothing else in the save changes.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.12.zip` and copy each program over the old one.

New text is translated into all six languages.
