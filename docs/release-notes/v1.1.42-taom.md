### What is new in v1.1.42

**Coop Save Rescue now runs on every Start server and Restart.** The TAOM server tool loads it inside DedicatedServer.Windows, so players can join while it is on and a save made with it still loads without it. It fixes the known save problems by itself (a saved open menu, the host party inside an enemy town, a broken or empty battle, parties stuck in a battle that already ended, a killed lord still alive in the save). When it fixes something, the tool keeps a backup from before the fixes, saves the game and shows a note at the top until you press **Dismiss**.

**One more start after a crash on load.** If the server crashes while the save loads, the tool starts it once more with the deeper save fixes, which also skip a hero that fails to load. It never does this twice in a row. If that start crashes too, the note says so and tells you to click **Send my logs**.

**A check after Stop.** After **Stop**, the tool reads the log of that run and tells you when the save has a problem the next Start fixes. When Coop already freed parties from an ended battle by itself, it only shows a short note that Coop freed them.

**Run Rescue save moved to the Logs page.** It runs every fix once, lords stuck with an empty party too, for support tickets or a save Start did not fix.

**Cheats page.** Custom commands moved from the Cheats page to the Console page, which lists every Coop command and keeps your recent ones. After **Join a kingdom** the page now says that Coop still turns it down for a clan below tier 2, because Coop only says that in the server log.

**Report a mod in one click.** Report a mod is right at the top of the TAOM client. Pick Works or Broken for each mod and send it, with no GitHub account and no Discord message. After a crash the red bar asks you to tell everyone which mod broke, and when the crash log names a mod it is already marked Broken. **Mod crashed? Report it** under Connect does the same any time, and after a game a small bar asks how your mods worked. Close that bar three times in a row and it stays away.

**Report counts on the Mods page.** Every mod shows a green chip with how many players say it works and a red one with how many say it is broken, so you can see which mods are safe before you play. Reports are anonymous, the first send shows exactly what is sent, and Coodsz checks every report before it counts.

**Crash reports instead of log zips.** Crashed? Click **Send crash report** on the red bar. The tool packs your cleaned logs, shows you every file and sends them only when you click **Send**. You get a short code to post in Discord instead of a zip file. The TAOM server tool shows a big **Send server crash report** bar when the server crashes or stops by itself.

**Send my logs is always on the main page** of both TAOM tools, for a stuck join, a desync or lag, and it also sits next to Connect and Start server. Your Windows name, PC name, Steam ids, addresses and passwords are taken out before anything is packed, and crash dumps are never sent. Logs can still show in game player names. **Save a copy instead** keeps the same zip on your PC. The old log zip buttons are gone.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
