### What is new in v1.1.14

**Both tools, MCM 5.13.1.** The AD1259 tools now take MCM v5.13.1 from the Steam Workshop and still take v5.12.3 from Nexus Mods, so the Client Launcher no longer keeps **Connect** off with "Newer than this tool supports". An MCM in the game's Modules folder next to the Workshop one no longer counts as installed twice. **Start server** gives the server the MCM version your game loads. Every player needs that same version to join. If the new MCM can't be copied, the server keeps its old one.

**Server Tool, saves and the Logs page.** When a mod's version changed since a save was made, the **Logs** page now names that mod and both versions instead of saying the mods don't match. The **Logs** page also shows its What happened, What to do and What not to do lines in the language you picked. Before, they stayed in English.

**Server Tool, a frozen map when the server's own hero is a prisoner.** Save Rescue now keeps the map moving when a save has the server's own hero, the one nobody plays, as a prisoner (seen with TAOM). Before, the server kept opening a captivity menu and every party stood still. The hero stays a prisoner, and nothing else in the save changes.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.14.zip` and copy each program over the old one.

New text is translated into all six languages.
