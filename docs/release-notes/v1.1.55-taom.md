### What is new in v1.1.55

**Updates no longer remove another Coodsz tool or your own files.** From this version on, **Install update** removes only the files that belong to the tool you update: its own program and the files that came with it. Another Coodsz tool in the same folder stays, and so does any file of your own.

**Each TAOM zip now also holds the other TAOM tool**, so updating the Client Launcher or the Dedicated Server Tool in a folder they share keeps the other one. After this update a folder that had only one TAOM tool also shows the other one. That is expected, and it is fine to leave it there.

Keep each Coodsz tool in its own folder. This one update is still installed by the version you have now, so it can still remove another Coodsz tool or a program file of your own (.exe or .dll) in the same folder, but never the other TAOM tool. If a Coodsz tool goes missing, unzip it again from its release zip.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
