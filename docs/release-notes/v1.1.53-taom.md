### What is new in v1.1.53

**For hosts: Start server puts back missing server files.** When BannerlordCoopServer.exe or other server program files go missing from the server folder, most likely removed by antivirus, **Start server** now puts them back from the TAOM host kit. It checks each file against the kit's hashes first and never touches the Data folder or your saves. **Prepare server** no longer leaves you stuck and points you to **Start server** instead. If a file can't be put back, the tool says to restore it from your antivirus quarantine and add the server folder as an exclusion.

**For hosts: commands keep letters like Ü or İ.** Commands you send from the TAOM server tool, like say, now reach the server with those letters intact.

**Crash reports: the crash dump sentence shows only with a dump.** The crash report window now mentions the crash dump only when there is a dump to add.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
