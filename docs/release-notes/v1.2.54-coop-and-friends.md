## Hover tips on every button

- **Hover over any button to see what it does.** Every button, switch, check box, list and menu item in Coop and Friends and Coodsz Host now has a short tip that says what it does, and why when it is turned off. Number and port boxes that are not obvious have one too.
- The tips show after a short moment, stay while you read them, and also show on buttons that are off.

## Asks before deleting

- **Delete setup in Coodsz Host asks first.** It used to delete the setup and its own MCM settings straight away. Now it names the setup and only deletes after you confirm.
- **Remove on a saved cheat command asks first** on the Cheats page under Saved commands.

## Small fixes

- When RBM had no settings file yet on the server PC, the file Coodsz Host wrote was reset by RBM to its defaults, which turned RBM's Campaign part back on. The new file carries the version RBM expects, so Campaign stays off as you set it.
New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
