### What is new in v1.1.40

**Rescue save fixes killed lords still marked alive.** A save could crash the server on every load (0xC0000005 right after "weather behavior unregistered") when a lord who was executed or killed was still marked alive with his hero data gone. **Rescue save** now finds those lords, marks them dead with the game's own function, and writes a FIXED line for each. One bad hero can no longer stop the whole save from loading either. Run **Rescue save** once, let the server save, and the campaign loads normally again.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
