## Hover tips on every button

- **Hover over any button to see what it does.** Every button, switch, check box, list and menu item in the AD1259 client launcher and the AD1259 server tool now has a short tip that says what it does, and why when it is turned off.
- The tips show after a short moment, stay while you read them, and also show on buttons that are off.

## Asks before deleting

- **Remove on a saved cheat command asks first** in the server tool's Cheats page, under Saved commands.

## Small fixes

- When RBM had no settings file yet on the server PC, the file the server tool wrote was reset by RBM to its defaults, which turned RBM's Campaign part back on. The new file carries the version RBM expects, so Campaign stays off.
- The server tool's texts about the campaign map name the AD1259 client launcher, not Coop and Friends.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
