### What is new in v0.1.1

**Server Tool, Prepare server.** Prepare server no longer looks like it does nothing. When something stops it, like Coop missing from the Steam Workshop, the reason now shows on the **Saves** page too, not only on the **Dashboard**.

![The Coodsz Realm of Thrones download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-RealmOfThrones/main/images/Coodsz-RealmOfThrones-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Realm-of-Thrones-Tools-v0.1.1.zip` and copy each program over the old one.

New text is translated into all nine languages.

The full steps are in README.-.Instructions.txt on this page: https://github.com/Coodsz/Coodsz-RealmOfThrones/releases/latest
