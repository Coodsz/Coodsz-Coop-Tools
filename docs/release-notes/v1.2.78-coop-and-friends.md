## Campaign names in any language

**For hosts, a new campaign name can use letters from any language.** Coodsz Host now takes a new campaign name like YÜZÜK TEST, with letters from any language, numbers, spaces, hyphens and underscores. Path characters are still not allowed. The tool checks the name against the server folder's own start script before the server starts, so if an older copy of that script only takes the English letters A to Z (a file kept open can stop the update), **Start server** says so in plain words. Pick a name with A to Z, or close anything that has the server folder open and click **Start server** again. A save that already has other letters still loads.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
