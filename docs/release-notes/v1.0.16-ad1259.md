## Translation fixes

- **The Settings page in your language.** The dropdowns show On, Off, Very easy and the other choices in your language, and the notes next to them use the same words. The files the server reads are not changed.
- **The number settings under Other explain themselves.** Each one now says what a higher or lower value does, and the range you can use.
- **Clearer wording** in every language for the mods page, Save module config and Auto dependency order.

Nothing else changes in this release. Click **Install update** in the tool, or unzip over your folder and choose Replace.
