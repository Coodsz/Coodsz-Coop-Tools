### What is new in v1.0.3

**Start server prepares the server for you.** If the server folder isn't ready yet, **Start server** in the Server Tool now prepares it by itself. You don't have to click **Prepare server** first.

**Clearer messages when the Coop download isn't right.** **Prepare server** now checks the Bannerlord Coop download from the Steam Workshop first. If Steam is still downloading Coop, it tells you to wait for Steam. If the download is missing files, it tells you to unsubscribe and subscribe again. Before, it only said the server was not found.

**Antivirus help.** When a file the tool put in place goes missing later, the tool now says your antivirus most likely removed it and how to get it back. The new **Fix antivirus** button lists the folders your antivirus should skip and opens Windows Security. It changes nothing on your PC by itself.

**Play stays on.** In the Server Tool, **Play** now stays on until you press **Pause**, also when every player is in a town or a battle.

**Easier first campaign.** With no campaign yet, the Server Tool tells you to type a name in step 1 and click **New campaign**. You don't need a single player save.

**Also new**
- The new **Donate** button next to **What's new** lists Coodsz's Linktree with Patreon and PayPal, and Buy Me a Coffee under it. The tools stay free either way.
- **Install update** is safer. The tool updates itself without a hidden PowerShell script, and when an update fails it puts the old version back so the tool still starts.
- When the game or the server crashes and Windows kept a crash dump, the crash report now adds a short text of the crash stack, read on your PC. The dump itself is only sent when you tick it.
- Save backups now work for a campaign that lost its .json file or its .sav, and putting a backup back over a missing save can always be undone.
- After you import a single player save, the Server Tool reminds you that only Sandbox campaigns run on a Coop server.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.3.zip` and copy each program over the old one.

New text is translated into all six languages.
