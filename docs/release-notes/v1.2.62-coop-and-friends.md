## Save fixes on every start

**Coop Save Rescue now runs on every Start server and Restart.** Coodsz Host loads it as the server only module DedicatedServer.CoopSaveRescue, so players can join while it is on and a save made with it still loads without it. It fixes the known save problems by itself (a saved open menu, a broken or empty battle, parties stuck in a battle that already ended, a killed lord still alive in the save). When it fixes something, Coodsz Host keeps a backup from before the fixes, saves the game and shows a note at the top until you press **Dismiss**.

**One more start after a crash on load.** If the server crashes while the save loads, Coodsz Host starts it once more with the deeper save fixes, which also skip a hero that fails to load. It never does this twice in a row. If that start crashes too, the note says so and tells you to click **Send my logs**.

**A check after Stop.** After **Stop**, Coodsz Host reads the log of that run and tells you when the save has a problem the next Start fixes. When Coop already freed parties from an ended battle by itself, it only shows a short note that Coop freed them.

**Run Rescue save moved to the Logs page.** It runs every fix once, lords stuck with an empty party too, for support tickets or a save Start did not fix.

## Cheats page

**Custom commands moved to the Console page.** The Console page lists every Coop command and keeps your recent ones, so the custom command boxes are gone from the Cheats page.

**Join a kingdom no longer says Done when Coop turns it down.** Coop queues the request and then refuses a clan below tier 2, only in its log. The Cheats page now says so up front and tells you to use **Set clan tier** first.

## Report a mod in one click

**Report a mod is right at the top of the tool.** Click it, pick Works or Broken for each mod and send it. You don't need a GitHub account or a Discord message.

**After a crash the red bar asks which mod broke.** Click **Tell everyone which mod broke**. When the crash log names a mod, it is already marked Broken, so you only check it and send. **Mod crashed? Report it** under Connect does the same any time.

**After a game a small bar asks how your mods worked.** Close it three times in a row and it stays away.

**Every mod on the Mods page shows its reports.** A green chip says how many players say it works and a red one how many say it is broken, so you can see which mods are safe before you play.

**Reports are anonymous.** The first time you send one, the tool shows exactly what is sent, and Coodsz checks every report before it counts.

## Crash reports instead of log zips

**Crashed? Click Send crash report on the red bar.** The tool packs your cleaned logs, shows you every file and sends them only when you click **Send**. You get a short code to post in Discord instead of a zip file.

**Coodsz Host shows a big Send server crash report bar** when the server crashes or stops by itself, with the server logs ready to go.

**Send my logs is always on the main page**, for a stuck join, a desync or lag. It also sits next to Connect and Start server.

**Your private details stay out.** Your Windows name, PC name, Steam ids, addresses and passwords are taken out before anything is packed, and crash dumps are never sent. Logs can still show in game player names. **Save a copy instead** keeps the same zip on your PC. The old log zip buttons are gone.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
