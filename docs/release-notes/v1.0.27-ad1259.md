## Server keeps running when a boy is born, old MCM stopped before it crashes the server, and version numbers kept in reports

**A male child being born no longer stops the server.** Coop 0.1.6 crashed on the daily tick when a boy was born. Coop Save Rescue, which the AD1259 server tool already loads on every server start, now fills in the missing name first, so the server keeps running. Update the tool and start your server again.

**An old Mod Configuration Menu no longer crashes the server.** Start server in the AD1259 server tool now stops before the game loads when Mod Configuration Menu (MCM) is older than v5.12, because an old MCM crashes the dedicated server. The tool tells you what happened and how to fix it: get MCM v5.12 or newer from the Steam Workshop or Nexus Mods, then press Start server again.

**Version numbers stay readable in reports.** Crash reports and log zips from the AD1259 client launcher and server tool now show version numbers like 3.0.3.0 as they are, instead of hiding them like an address. Real IP addresses are still taken out.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
