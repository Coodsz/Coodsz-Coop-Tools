## RBM is set in each player's own game

- **RBM's campaign rules run in each player's own game, not on the Coop server.** RBM's code does not run on the dedicated server at all, only its item and troop data loads there. So the setting that matters for coop has to be right on every player's PC.
- **Connect now keeps RBM coop friendly.** When RBM is in your setup, Connect turns off RBM's Lords buy equipment in your own RBM settings before the game starts. That setting makes lords buy up the gear in every town they enter, which empties the town markets in coop. Only that one value changes, a config.xml.bak is kept the first time, and the log says what was changed.
- **Keep RBM coop friendly** is a new check box under Connect. It shows while RBM is in your setup and is on by default. Untick it to keep your own RBM settings.

## RBM settings card in Coodsz Host

- **RBM settings for this PC's game.** When RBM is in your setup, the Settings page has a card with RBM's four parts and its main campaign options, with a short line on what each one does. It edits RBM's config.xml on this PC, the file your own game reads when you play from this PC.
- **Coop friendly** turns off Lords buy equipment and leaves the rest alone. **Save RBM settings** changes only the values you changed and keeps a config.xml.bak the first time. **Read the file again** shows what the file says now.
- **Start server no longer changes RBM's settings.** The Coop server does not run RBM's code, so writing RBM's parts there did nothing for the server and only changed the host's own game on that PC.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
