### What is new in v1.1.5

**AD1259 set check.** When the AD1259 set is not complete, the Server Tool now shows the version each mod needs, the one the server has and the one on this PC, so an old copy on your PC is easy to spot.

**Map mods on an older campaign.** **Start server** now stops before it adds a map mod to a campaign made on another map, because that save would not load. Start a new campaign on that map instead.

**My reports is easier to see.** My reports is now a real button next to **Send my logs**. When Coodsz answers one of your reports, the button glows gold with a red count, and a banner at the top says which report got an answer. Click **Open** on the banner to read it. The banner goes once you have read every answer.

**Faster answers.** Answers to your reports now reach the tool much sooner. Right after you send a report it checks every half minute, then every few minutes while you wait, instead of every 30 minutes. It does not check while it is minimized.

**Players' time buttons.** Players' pause, play and fast forward buttons now work on servers whose settings file came from an older Coop version. The Server Tool turns them on at the next **Start server**, the way its Settings page already showed them.

**Console commands.** Typing save, status, players, say, kick or help on the Server Tool's Console page now works. Before, the server refused them. To stop the server, click **Stop**, which saves first.

**A blocked file is not a mod.** When something on your PC blocks the start script from writing a file, the Server Tool now says so and what to check in Windows Security, instead of blaming one of your mods.

**Common setup problems get their fix.** The crash screen and **Send my logs** now spot five common setup problems and show the fix. They are Smart App Control, a leftover Common.dll or 0Harmony.dll in the game's bin folder, a DNS changer like Cloudflare WARP blocking the Steam join, and Documents in OneDrive. When you click **Connect**, the Client Launcher also checks the game's bin folder for those two leftover files and says which one to move out. On **Send my logs** the fix is only a hint, so you can still send your logs.

**Server Tool sidebar.** Long button names now fit in every language instead of being cut off, and on a small window the page list scrolls instead of disappearing.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.5.zip` and copy each program over the old one.

New text is translated into all six languages.
