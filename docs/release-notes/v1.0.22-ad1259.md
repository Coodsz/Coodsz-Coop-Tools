## Get all missing

**One click gets the missing Workshop mods.** **Get all missing** in the launcher now has Steam subscribe to the missing Workshop mods of the pack and download them by itself. The Nexus mods still open their page, since only you can download those.

## A tidy card when a save needs other mods

**One click fixes a save that needs mods your setup leaves out.** Start server in the AD1259 server tool now shows a tidy card on the Server page with the missing mods as chips and one button that does the fix. It turns the mods back on, switches to the setup the save was made with, or opens Add mods when a mod is not on the server yet. **Use a different save** lets you pick another save instead.

## Tested verdicts and a calmer Mods page

**The Mods page shows what ModderLords tested.** Next to the green and red player counts the AD1259 launcher now shows the verdict from the compat records by Ryvius, like Tested works, Tested broken or Works with settings. It also tells you when he tested an older version than the one you have.

**The Your mods card is calmer.** It has one short line, **Add mods** as the main button next to **Check mods** or **Install mods**, and the rest in a **More** menu. **Save mods** only shows while a change is waiting, and a small mod count sits by the title.

## One less server crash

**A kingdom with no leader no longer crashes the server.** When a war was declared and a kingdom on either side had no leader, the server shut down with "Failed to run Game.OnTick". It happened on TAOM's War of the Ring day, when Isengard declares war and its allies are asked to join. Coop Save Rescue now lets the war go ahead, gets past the call to war that crashed, and lists it with the other save fixes. It only steps in when the game really crashes there.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
