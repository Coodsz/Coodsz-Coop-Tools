## New Cheats page and a license

- **New Cheats page in the server tool.** Pick a player card, pick a cheat, fill in the boxes and press **Run**. Every cheat sends Coop's own command and shows you the exact line, with Undo where it can. Your saved commands are still there under Saved commands.
- **A license for the tools.** The tools stay free to use. Making money with them, decompiling them, reuploading them or sharing changed copies needs written permission from Coodsz. It shows once, and one **I agree** covers all Coodsz tools. The full text is in LICENSE.txt.
- **UIExtenderEx missing a file.** Check mods says which file is missing and how to get it back, and Connect turns off UIExtenderEx's Compiled Prefabs for that game until then, so the game still starts.
- **Steam not ready on the host.** The server tool now says when the Steam lobby did not start because Steam was not open or logged in, and to press **Restart**.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
