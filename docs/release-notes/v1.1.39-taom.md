### What is new in v1.1.39

**New Cheats page in the server tool.** Pick a player card, pick a cheat, fill in the boxes and press **Run**. Every cheat sends Coop's own command and shows you the exact line. Your saved commands are still there under Saved commands.

**A much bigger Console page.** Live server output, recent commands you can run again with one click, and every Coop command in one list by category, each with a How to use guide, **Use example** and **Find ids**.

**A license for the tools.** The tools stay free to use. Making money with them, decompiling them, reuploading them or sharing changed copies needs written permission from Coodsz. It shows once, and one **I agree** covers all Coodsz tools. The full text is in LICENSE.txt.

**UIExtenderEx missing a file.** If UIExtenderEx is in your launch list and is missing one of its files, Check mods says so and Connect turns off its Compiled Prefabs for that game, so the game still starts.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
