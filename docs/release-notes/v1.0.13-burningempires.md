### What is new in v1.0.13

**Server Tool, a frozen map when the server's own hero is a prisoner.** Save Rescue now keeps the map moving when a save has the server's own hero, the one nobody plays, as a prisoner. Before, the server kept opening a captivity menu and every party stood still. The hero stays a prisoner, and nothing else in the save changes.

The Client Launcher only got a new version number.

![The Coodsz Burning Empires download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-BurningEmpires/main/images/Coodsz-BurningEmpires-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.13.zip` and copy each program over the old one.

New text is translated into all six languages.
