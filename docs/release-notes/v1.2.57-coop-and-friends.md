## Plain Coop, with no mods at all

- **New locked setup "Plain Coop (no mods)" in Coodsz Host and Coop and Friends.** The host picks it and starts a Coop server with only the game and Coop, no other mods. Friends pick the same setup in Coop and Friends to join it. Good for a quick vanilla game, or to see if a problem comes from a mod.

## Max clans per kingdom (Coodsz Host)

- **A new setting on the Settings page, in the Kingdoms group.** It is the most clans one kingdom can have, its ruling clan included. A full kingdom cannot take more clans, from players or the AI, so one kingdom cannot swallow every lord on a big server. Clans already in a kingdom always stay.
- **What it caps.** Players joining as vassals, a player ruler recruiting an AI lord (the player sees why the barter is refused), and the AI choosing to join or defect to a full kingdom. Tick **Count mercenaries** to count mercenary clans too, so a full kingdom also cannot hire more. New kingdoms, rebellions, clans leaving and marriages work as before.
- **Where it is kept.** `Documents\Mount and Blade II Bannerlord\CoopData\DedicatedServer\coodsz-server-tools.json`, next to server-config.json, with the keys `maxClansPerKingdom` and `countMercenaries`. You can edit it by hand too.
- **It applies live.** The server reads the file again within a few seconds, so there is no restart, and players need nothing. After Save settings the note says so.
- **0 means no limit, and that is the default.** With 0 or no file, nothing changes on your server. The server side lives in Coodsz Server Tools v1.4.0, the small server only module Start server adds by itself. Each refusal is one line in the server log.

## Adding mods to a campaign

- **A clearer "Add mods to this campaign" box.** It lists the new mods by their name, with the id beside it, says a backup of the save is made first, and warns that taking them out later can break the save.
- **Harmony and UIExtenderEx no longer trigger it.** They keep nothing in the save, so adding them is not a mod change. ButterLib and MCM do keep data in the save, so they still count.
- **Saves from an older patch load.** A save from the same game version and an older or equal patch (like Coop's own v1.4.6 start save on a v1.4.8 server) now shows and loads. A newer patch or another version is still hidden.

## Other changes

- **The working setups are named after Coop 0.1.6.** They are now "Working stable mods for Coop 0.1.6 - Vanilla campaign Map" and "Working stable mods for Coop 0.1.6 - More Nations Remastered Map". Your setup, its settings and its MCM folder carry over.
- **Translation fixes a Turkish player found.** The dropdowns on the Settings page show On, Off, Very easy and the other choices in your language, and the notes next to them use the same words (the files the server reads are not changed). The number settings under Other say what a higher or lower value does and the range you can use. The Community filter buttons on the Modules page are translated. Clearer wording for the mods page, Save module config and Auto dependency order.
- **Real names on the Cheats page.** The Cheats page and the player profile show each player's hero name, or their Steam name while the server is stopped, with the hero id under it. Streamer mode still shows Player 1, Player 2.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events, backups, bans, settings catalogue and compatibility list, and for the Home, Players, Cheats, Map, Encyclopedia and Guides pages. See THIRD-PARTY-NOTICES.md in the zip.
