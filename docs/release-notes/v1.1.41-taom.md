### What is new in v1.1.41

**No more crash at launch after using Coop and Friends.** Coop and Friends edits the Steam Workshop copy of `Coop.Core.dll` so Connect can send the join password. TAOM.CoopCompat refuses an edited file and the game crashed right after loading it. The TAOM client already put back the copy in the Modules folder, and now it puts back the Workshop copy too, so a Workshop only Coop works again.

**Joining no longer gets stuck on Final Synchronization.** When a few parties went missing while a player's game loaded the campaign, Coop refused the join and retried until the player sat on **Final Synchronization** forever. The client fix that comes with the tools now puts back the parties the server says are there, and writes each one to `Documents\Mount and Blade II Bannerlord\Client Diagnostics\CoodszJoinPassword.log`.

**The server no longer stalls behind the server tool.** The TAOM server tool rebuilt its whole log text for every server line. During a burst of log lines that slowed the server down. It now keeps the log cheaply and checks only the newest lines.

**Server is ready.** Once the server is serving, the status note now says **Server is ready** instead of still showing the starting note, so nobody presses Start again.

**BattleSizeResized note.** When BattleSizeResized is in your setup, the client and server tools now tell you it overrides the server's battle size, so the **Field battle size** from the server tool does not apply, and how to fix that.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
