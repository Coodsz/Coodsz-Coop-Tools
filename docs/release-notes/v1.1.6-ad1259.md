### What is new in v1.1.6

**Coop v0.1.7.** The AD1259 set now takes Coop v0.1.7 and still takes v0.1.6. The host and every player need the same Coop version to join, so move over together.

**Coop v0.1.7 installed by hand.** Coop v0.1.7 is out on Coop's GitHub release and on ModDB. It has to end up as `Modules\Coop`. The GitHub zip already holds a Coop folder, so unzip it into the game's Modules folder. The ModDB download has no Coop folder inside, so make a folder named Coop in Modules and unzip it into that. The game loads that copy before the Workshop Coop, so the Client Launcher checks that one, its Coop row says Modules, and it no longer calls it a second copy next to the Workshop Coop.

**Coop in the wrong folder.** The ModDB download has no Coop folder of its own, so it is easy to end up with the wrong layout. When Coop is in a folder with another name, has a second copy, sits inside another folder, was unzipped straight into Modules or is one folder too deep, **Check mods** says what to rename or move.

**Downloaded files unblocked.** Windows marks unzipped files as downloaded from the internet, and the game won't load a marked DLL. The Client Launcher now unblocks Coop's files on **Check mods** and before the game starts, and the Server Tool unblocks the server's files on **Start server**.

**The v0.1.7 dedicated server.** The Server Tool works with Coop's v0.1.7 dedicated server package. Unzip it to a short folder like `C:\CoopServer`, click **Set server folder** and choose BannerlordCoopServer.exe. The Active Coop line on the Modules page now says whether the server's Coop comes from the Steam Workshop, the game's Modules folder or the server folder you chose.

**Steam advertise stays on.** A fresh Server Tool setup no longer turns **Steam advertise** off. It and **Write server log** now start ticked, the way Coop has them.

**Password and Steam advertise reach the server.** **Start server** now writes the **Server password** and **Steam advertise** into the server's settings, so you don't need **Save settings** first. An empty password box clears the password, and the log says so.

**A new campaign stays new.** After a crash or CoopModPatch's first setup stop before its first save, the campaign stays new. Before, the next **Start server** refused it with That save is not in the dedicated server Game Saves folder.

**Smithing stamina.** On a Coop v0.1.7 server, Smithing stamina recovery multiplier starts at 0.6, Coop's new default. Coop v0.1.6 servers keep 0.1.

**Join errors.** When Coop v0.1.7 refuses a join over a missing or wrong mod, the tools explain it again. Coop v0.1.7 writes mod names in a new way.

**Smaller fixes.** The two movement limit boxes on the Settings page are gone, because Coop never read them. The Client Launcher no longer blames antivirus for a Coodsz add on that was never installed.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.6.zip` and copy each program over the old one.

New text is translated into all six languages.
