### What is new in v1.3.1

**Births no longer stop the server.** A child born to a player's character used to stop a Coop 0.1.6 server. Coop Save Rescue now fills in what the game needs before the birth, so the server keeps running.

**Improved Garrisons party sizes.** With Improved Garrisons and another mod that changes party sizes, that mod's party sizes now count too, on the server and for every player. With Improved Garrisons alone nothing changes. Players get the fix when they update the Client Launcher.

**Server commands wait for the answer.** A command the server turned down no longer shows as done.

![The Coodsz Coop download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-Coop-and-Friends/main/images/Coodsz-Coop-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Coop-Tools-v1.3.1.zip` and copy each program over the old one.

New text is translated into all six languages.
