### What is new in v1.1.45

**The War of the Ring bar works for players who join.** TAOM keeps the War of the Ring only on the server, so players who joined never saw the bar on the map until they rejoined, and then its numbers stayed frozen from the moment they joined. Now the server tool adds a small Coodsz War Sync to the server at every Start. It sends the war's phase and momentum to the players, so the bar shows as soon as the full war starts and its numbers move with the server's. Their game also follows the server's war phase, so TAOM's peace rules match what the server does.

It works by itself, with nothing to set up. The host needs this version of the TAOM server tool, and players need this version of the TAOM client launcher, which brings the client add on. It only sends the war state: mod settings, server rules and everything else stay as they are, and the TAOM module list and your saves are not changed. A player with an older client launcher can still join; the bar just stays as before for them.

**Tell Coodsz what happened, and add screenshots.** Send my logs, Send crash report and Send server crash report now have two optional extras:

- **Tell us what happened**: a box for your own explanation, up to 2000 characters. Your Windows name, PC name, Steam ids, addresses and passwords are taken out of it the same way as from the logs.
- **Add screenshots**: up to 5 PNG or JPG pictures. You can also copy a picture and press **Ctrl+V** in the window. Each one shows as a small picture with a remove button. Very large pictures are made smaller, and hidden details like the camera, place or time a picture was taken are removed. The pictures themselves are sent as they are, so check them for anything private first.

Both are optional, so Send with nothing added works like before. **Save a copy instead** keeps your text and screenshots in the zip too.

**The server tool says when players can join.** Once the status says Serving, the note under **Start server** now says **Server is ready. Players can join now.** Before, the starting note about the map cache could stay up, so players thought the server was still loading and pressed Start again. It is swapped in every language, and also after a start that switched the setup or loaded a backup.

**Save settings no longer stops on an empty number box.** An empty battle size or gameplay number box now keeps the value the file already has, and when the gameplay settings could not be read the page is skipped, so the server settings and fast forward choice still save.

**The client launcher opens inside your screen.** On a small screen or with display scaling the window used to open wider than the screen. It now fits, and the update bar with **Install update** stays at the top while you scroll the page.

**The Cheats page lost its old More cheats section.** Everything in it is on the page above: Set gold is in the Gold category, Give influence is in the Clan category, the player cards show who is online, and the **Console** page has the console.

**Reporting a mod is easier to find.** A short line under the title of the client launcher, *Played with mods? Tell others if they worked.*, points to **Report a mod**, and each extra mod in your setup now has a small **Report** link. The report window shows what is sent from the start, so one click on **Send** sends it. On plain TAOM with no extra mod, **Report a mod** now says there is nothing to rate yet instead of doing nothing.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
