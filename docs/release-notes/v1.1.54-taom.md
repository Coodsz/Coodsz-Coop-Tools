### What is new in v1.1.54

**For hosts, Start server puts back game files antivirus removed.** When 0Harmony.dll or the GauntletUI files go missing from the server's engine folder, most likely removed by antivirus, **Start server** now puts them back from the Workshop Coop server, checking each file against its known hash first. A Harmony from a client mod is never used. If a file can't be put back, the tool names the missing files and says to restore them from your antivirus quarantine and add the server folder as an exclusion, or to verify Bannerlord in Steam.

**For hosts, a crash from missing files is no longer a save load crash.** When the server stops because those files are missing, the tool no longer retries in load mode or runs Coop Save Rescue on your save, and the crash bar names the missing files instead.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
