# Discord announcement, Coodsz Realm of Thrones tools v0.1.0

Paste the text inside the block as one message. It stays under 2000 characters, has no colons and no hyphens between words.

```
**Coodsz Realm of Thrones tools v0.1.0 are out**

These are the first tools for hosting and playing Realm of Thrones 8.1.2 in Bannerlord Coop. They are early, so please tell me what breaks. You need Bannerlord 1.4.8 on Steam for Windows and the War Sails DLC.

**One zip, two programs**
The zip holds the Server Tool and the Client Launcher. Unzip it into its own folder. They carry their own .NET and an unofficial Realm of Thrones build of Coop, so host and players run the same one. The tools never contain Realm of Thrones, so get it from Nexus Mods yourself.

**Players**
1. Close Bannerlord and open the client launcher.
2. Ask the host for their mod list, then click "import mod list" on the mods page.
3. Click "check mods" on the play page, then click "connect".
Your first join takes several minutes while the game rebuilds its shaders. Wait for it.

**Hosts**
1. Click "prepare server", then type a name and click "new campaign".
2. Click "start server" and allow it in Windows Firewall.
3. Click "share mod list" and send the file to your players.
The server is built in this folder.
`C:\RotServer`

**Also in this release**
The "encyclopedia" page opens the Realm of Thrones wiki and tables in your browser. Story questions go to every player, the first answer decides and the default goes ahead after 60 seconds.

**Something broke**
Click "send my logs" in either tool, like in the other Coodsz tools, and post only the short code you get.

**Not finished yet**
Sieges are still being tested. The White Walker start is not offered in a Coop game. Enlisting, duels, storyline wars and ravens are off in Coop. Dragons are not tested in Coop yet.

Download the tools and read the full steps here.
https://github.com/Coodsz/Coodsz-RealmOfThrones/releases/latest

Tell me in this thread if anything breaks.
```
