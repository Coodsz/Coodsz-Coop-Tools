# Discord announcement, Coodsz AD1259 tools v1.0.13

Paste the text inside the block as one message. It stays under 2000 characters, has no colons and no hyphens between words.

```
**Coodsz AD1259 tools v1.0.13 are out**

A quick quality of life update. Click Install update in both tools.

**Hover tips on every button**
Hover over any button in the AD1259 client launcher or the AD1259 server tool and a short tip tells you what it does. Switches, check boxes, lists and menu items have one too. If a button is turned off, the tip tells you why.

**It asks before deleting**
Remove on a saved cheat command in the server tool now asks first, so one wrong click no longer loses it.

**Small fixes**
If RBM had no settings file yet on the server PC, RBM threw away the file the tool wrote and turned its Campaign part back on. The tool now writes the file the way RBM wants it, so Campaign stays off. The map texts in the server tool also name the AD1259 client launcher now instead of Coop and Friends.

AD1259 coop fixes are by SkyApolo, bundled with permission. Let me know in this thread if anything acts up.
```
