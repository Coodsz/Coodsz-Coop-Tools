## One zip, two programs

**The server tool has a new name.** Coodsz AD1259 Server is now **Coodsz AD1259 Server Tool**. The client launcher keeps its name, **Coodsz AD1259 Client Launcher**. Both come in one zip, `Coodsz-AD1259-Tools-v1.1.0.zip`, with nothing else in it. The AD1259 modules are inside each program.

![The new Coodsz AD1259 download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-AD1259/main/images/Coodsz-AD1259-new-download.png)

**Your settings move by themselves.** They now live in %LOCALAPPDATA%\Coodsz\AD1259. Each program copies them there from its old folder on its first start, so keep the old folder until then.

**New icons.** The Server Tool and the Client Launcher each have their own Coodsz banner icon, and the Client Launcher's is a lighter shade, so you can tell them apart in the taskbar.

**Steam library fix.** A damaged Steam library file no longer stops the tools from finding Bannerlord and the Workshop mods.

### How to update

- **If you already have the tools,** click **Install update**. On its first start the server tool takes its new name, moves your Desktop, Start Menu and taskbar shortcuts to itself, and removes the old exe. If a shortcut can't be moved, the old exe stays and the next start tries again.
- **Updating by hand.** Close the tools, download `Coodsz-AD1259-Tools-v1.1.0.zip`, and copy each program into the folder where you already have that tool so it finds your settings. Choose Replace if Windows asks.
- **A new install.** Unzip `Coodsz-AD1259-Tools-v1.1.0.zip` into a folder of its own.

The two zips named Coodsz-AD1259-Server and Coodsz-AD1259-Client-Launcher are only there so older tools can update themselves. You don't need to download them.

New text is translated into all six languages.
