### What is new in v1.1.1

**Newer mods are named plainly.** When one of your AD1259 mods is newer than the tools support, they now say so and tell you to update the tools first.

**Births no longer stop the server.** A child born to a player's character used to stop the server. Coop Save Rescue now fills in what the game needs before the birth, so the server keeps running.

**Server commands wait for the answer.** A command the server turned down no longer shows as done.

![The Coodsz AD1259 download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-AD1259/main/images/Coodsz-AD1259-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-AD1259-Tools-v1.1.1.zip` and copy each program over the old one.

New text is translated into all six languages.
