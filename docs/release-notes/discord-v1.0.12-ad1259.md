**Help when something goes wrong**
Save logs for help is now one button in the client launcher. Click it and send me the zip.

**Server tool**
You can turn on Restart the server if it crashes. Your campaign gets a backup after every save, and Load backup puts one back. Stop and Restart let the server save first, and Restart warns players 30 and 10 seconds before. The status no longer says SERVING too early, and every Coop setting is on the Settings page now, kept for each campaign save.
