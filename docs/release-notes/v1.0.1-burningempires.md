### What is new in v1.0.1

**Install or repair asks before it opens your browser.** When your Burning Empires isn't the 2.0.2 one and a new download from Nexus Mods would fix it, **Install or repair Burning Empires** now says why and asks before it opens the Burning Empires page. Closing the file picker stops there, and nothing opens.

**Copied Burning Empires yourself? Only the hotfix is needed.** When the BurningEmpires and BurningEmpires_Elephants folders are already in the game's Modules folder, **Install or repair Burning Empires** only asks for the 2.0.2 hotfix you downloaded from Nexus Mods.

**Still copying? The tool waits.** When Burning Empires files in the Modules folder changed in the last minute, the tool asks you to let the copy finish first, so it never installs over a copy that is still running.

**Steam closed.** With Steam closed, the tools tell you to open Steam and sign in instead of opening Workshop pages. A Steam link that Windows can't open now shows a message instead of closing the tool.

**Find Bannerlord.** When a tool can't find Bannerlord, the new **Find Bannerlord** button lets you pick the game folder yourself. The tool remembers it.

**Answers to your reports show in the tool.** When Coodsz answers a report you sent, the answer now shows up right in the tool, so you don't have to wait for it in Discord. **My reports** next to **Send my logs** keeps your sent reports and every answer, with a search. If a fix did not help, click **Still not working? Ask Coodsz on Discord**. It opens the Coop Discord and copies a short message with your report code.

**A campaign that didn't load is never saved.** When a campaign fails to load, the Server Tool no longer saves over your save. **Save game**, **Stop**, **Restart**, **Rescue save** and backups leave it as it was.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.1.zip` and copy each program over the old one.

New text is translated into all six languages.
