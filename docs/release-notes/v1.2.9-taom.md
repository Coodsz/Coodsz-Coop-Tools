### What is new in v1.2.9

**TAOM still needs Coop v0.1.6.** TAOM.CoopCompat 0.3.25 needs Coop v0.1.6. Steam updated the Workshop Coop to v0.1.7 on October 30, so TAOM in Coop waits for a TAOM.CoopCompat made for it. The tools now say so plainly when Steam has the newer Coop. Before, the message said a Coodsz TAOM tools update would fix it, which was not true on its own. TAOM.CoopCompat comes from its own author, not from these tools. Players with a Coop v0.1.6 copy of their own in Modules can still join with it, and the Client Launcher still offers to set other Coop copies aside for it. Hosting a TAOM server needs a Coop v0.1.6 dedicated server until then.

**What comes next.** Once a TAOM.CoopCompat for Coop v0.1.7 is out, the Coodsz TAOM tools will be updated for it.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.9.zip` and copy each program over the old one.

New text is translated into all six languages.
