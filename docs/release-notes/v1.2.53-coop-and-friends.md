## New pages in Coodsz Host

- **Home is the first page now.** It shows the world that starts, one big Start or Stop button, Save game, Backup now and Restart, a strip with players, uptime, autosave, last save and last backup, the invite card and who is connected. Start and Restart on Home do exactly what they do on the Server page.
- **Create a world** on Home opens a short wizard. Pick a fresh campaign or a single player save, then a name, the difficulty, the rules and a join password.
- **Players page.** Online players with search, Profile, Cheats and Ban, and the ban list with Unban and Add SteamID. It takes over the player card from the Server page.
- **Player profile.** Skills, equipment, inventory and army of a player, with Show on map.
- **A new Cheats page.** Pick one player or several, then give or take gold, health, troops, influence, renown, clan tier, skills and items. The old saved cheat boxes are still there under Saved commands.
- **Map page.** The running campaign drawn live, with towns, castles, villages, kingdoms, players, lords, armies, battles and sieges. Click anything to see who owns it and what it is doing.
- **Encyclopedia.** Heroes, clans, kingdoms, settlements, troops and items of the running world, with a search and filters. It only reads the world and never changes it.
- **Guides.** Six short help pages, from getting started to common problems. They work without a server.
- **World presets.** Casual, Standard and Hardcore cards on the Settings page fill in the difficulty and the life and death settings. Nothing is written until you press Save settings.
- **Streamer mode** under the page list hides IP addresses, invite and reward codes, Steam ids and the join password on screen. Copy buttons still copy the real value.
- **Filter chips on the Modules page** show all mods, only the ones turned on or off, or the ones the community list calls Works, Broken, Client only or Unknown.
- The Cheats page, the profile, the Map and the Encyclopedia read the server through a small server only module, Coodsz Server Tools, that Start server adds by itself. Players do not need it.

## Easier joining

- **Coodsz Host lists the addresses your friends can use.** The Server page has a card with Steam lobby, Radmin VPN, Hamachi, ZeroTier or Tailscale, your public address, same Wi Fi and 127.0.0.1, each with a Copy button.
- **Copy invite** puts a short message for Discord on your clipboard with the address, the port and whether a password is needed. It never includes the password itself.
- **Open the port on my router automatically** (on by default) asks your router to open the server's UDP port while the server runs, and closes it again after the server stops or when you close the tool.
- **Allow through firewall** checks Windows Firewall first and only adds the rule after you confirm and Windows asks for permission.
- **How will friends join?** and the **?** buttons open a short guide for each way to join: Steam lobby, same Wi Fi, Radmin VPN or Hamachi, port forwarding, and playing on the host PC.
- **The launchers fill in 127.0.0.1 when the server runs on your own PC**, with the server's port. With Radmin VPN or Hamachi on your PC you get a short hint about using the host's VPN address.

## A safer server

- **Restart the server if it crashes** is a new option for each setup. It waits 10 seconds after the first crash and longer after each one, and gives up after more than 3 crashes in 10 minutes. It does not restart when the save does not load, when the Coop files fail their check, or when the server terms need accepting.
- **A backup after every save.** Each time the server writes the world (autosave, Save game, the save on stop) Coodsz Host zips that save into Save Backups. The last 10 are kept per save, none older than 30 days. **Load backup** lists them next to Coop's own backups while the server is stopped, and keeps a copy of the current save before it puts one back.
- **Stop and Restart let the server save and close by itself.** The server gets its own stop command and up to 2 minutes to finish, so the last minutes of play are kept. Only then is it ended.
- **Restart warns the players** in chat 30 and 10 seconds before the server goes down.
- **Safer bans.** Ban player and Add SteamID only take real SteamID64 numbers, and the ban list is written in one go so the server never reads half a list.
- **The status follows the server's own messages.** The start banner no longer shows as SERVING a few seconds after Start, STOPPING shows while it shuts down, and a crash after the server was ready is told as a crash with its exit code.
- **CPU and memory line.** While the server runs, a small line under the Server overview cards shows its CPU and RAM use.
- **Set gold works on more servers**, and a cheat the server does not know now says so in plain words.

## Settings

- **Every Coop setting is on the Settings page.** The usual ones stay at the top, the rest are under **Show more Coop settings**, grouped like mod-config.json. Empty boxes show Coop's own default, and a number outside the allowed range is refused with the range.
- **Settings are kept for each campaign save.** Save settings remembers them for the picked save, and Start server writes them into mod-config.json for that save.
- **Game speed on the Server page.** The Game time card says whether 2x speed and the battle speed limit are on, with buttons to turn them on or off. It tells you when the change needs a restart and offers Restart server. On the Settings page those settings now sit together in a Game speed group near the top.

## Mods

- **Community badges.** The Modules page and the Coop and Friends mod list show Works, Broken, Client only or Unknown for each community mod, with the note and the report counts on hover. Click the badge to open the report form already filled in with the mod, its version and the Coop version.
- **Your own results.** Next to that badge you see Worked for you, Crashed for you, Passed on your server or Failed on your server. A result for an older version of the mod is dimmed. Mods no list knows show Unknown, not tested.
- **Test mods on the server** (Modules page, next to Add mods). It tries each ticked mod alone with the working Coop core on a throwaway campaign, then tells you which ones load and why the others did not. Your real saves and module lists are put back as they were. Copy results into the mod list file makes a file Coodsz can add to the community list.
- **Adding Diplomacy.CoopCompat to a running campaign keeps the save usable.** The save check no longer counts the Coodsz patch modules (Diplomacy.CoopCompat and StuckBattleFix), so the save is not hidden as made with other mods.
- **Add mods to a running campaign.** When your setup only adds mods to a save, Start server asks once, keeps a backup, then loads the save with the new mods. A save missing a mod it was made with is refused with a plain reason, because taking mods out can break a campaign.
- **Locked tag.** Locked setups show a small Locked tag next to the setup name in Coodsz Host and in the Coop and Friends launcher, with a line on how to change mods. Buttons that are off say why when you hover them.
- **Community list update.** The compatibility list has the Coop 0.1.6 verdicts from the Coodsz compatibility thread on Discord, with the community patches each mod needs.

## Launchers

- **Save logs for help** replaces Save all logs to one zip and Open client logs. The small arrow next to it opens the other choice.
- **The Steam line no longer says Steam is closed while it is running.**

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
