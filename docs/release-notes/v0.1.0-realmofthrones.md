## The first Coodsz Realm of Thrones tools

This is the first release, so expect some rough edges and please report them.

**One zip, two programs.** `Coodsz-Realm-of-Thrones-Tools-v0.1.0.zip` holds **Coodsz Realm of Thrones Server Tool** and **Coodsz Realm of Thrones Client Launcher** and nothing else. The modules they need are inside each program, and they carry their own .NET, so there is nothing else to install.

![The Coodsz Realm of Thrones download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-RealmOfThrones/main/images/Coodsz-RealmOfThrones-new-download.png)

**The RoT build of Coop.** Realm of Thrones needs War Sails, and the Coop on the Steam Workshop does not have it yet. So both tools carry an unofficial Realm of Thrones build of Coop, and the host and every player run that same build. The tools check it before you join or start.

**For players.** The Client Launcher gets your game ready and joins the server. **Connect** puts the RoT build of Coop into the game's Modules folder. If another Coop is there, it asks first, sets it aside and puts it back when you close the launcher. Nothing of yours is deleted.

**For hosts.** **Prepare server** builds the server in `C:\RotServer` from the Workshop Coop server, War Sails from your own game and the RoT build of Coop. The Workshop folder is only read. Then type a name and click **New campaign**, and the server makes a fresh Realm of Thrones world.

**Setups.** **Plain Realm of Thrones** is the locked setup with only Realm of Thrones and its helper mods. **New setup** or **Copy** makes your own setup with extra mods, and every player loads the same ones.

**Story events.** Every player sees the Realm of Thrones story questions. The first player to answer decides for everyone, and after 60 seconds the default answer goes ahead.

**Encyclopedia.** The **Encyclopedia** page opens the Realm of Thrones wiki and the community tables of troops, armor, weapons, cultures, kingdoms and clans in your browser.

**Send my logs.** If something goes wrong, click **Send my logs** in either tool, like in the other Coodsz tools. You see every file first, then you get a short code like CR-7KQ2M. Post only that code on Discord. Saves are left out, and passwords, addresses and Steam IDs are taken out of the text logs. A crash dump, if you send one, is raw game memory and is not cleaned.

**Known limits**
- Windows only, Bannerlord 1.4.8 on Steam.
- Sieges are still being tested. In some tests the siege menu showed only **Leave**, with no way to start the assault, and one big battle at Casterly Rock stopped near the end.
- In a Coop game the White Walker start is not offered in character creation.
- Enlisting in a lord's party, changing the storyline wars and sending ravens are off in Coop. The game says so when you try.
- Duels are off in Coop. Dragons are not tested in Coop yet.
- The first join takes several minutes while the game rebuilds its shaders and prepares the map. Wait for it.

You need Bannerlord 1.4.8 with the War Sails DLC. Realm of Thrones 8.1.2 (modules 8.1.8, map 8.1.8.2) comes from Nexus Mods (mods/2907); the tools never contain it. Realm of Thrones Coop Compat 0.1.0 comes with both tools. The host also needs the Coop dedicated server from the Steam Workshop.

The full steps are in README.-.Instructions.txt on this page: https://github.com/Coodsz/Coodsz-RealmOfThrones/releases/latest
