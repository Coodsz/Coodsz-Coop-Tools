### What is new in v1.3.4

**PvP countdown.** With **Start the battle when the caught player doesn't answer** turned on, the caught player now sees a countdown like "Answer in 30 s" at the bottom of the screen, and the player who caught them sees how long is left. It stops on an answer, on peace, when the time runs out or when the host turns the timer off. Players see it when they join with the Coodsz Coop Client Launcher. Without it the timer works the same, just with no countdown.

**My reports.** A red badge on **My reports** now counts the reports with a new answer from Coodsz. Each report shows its status (Looking into it, Answered, Solved or Fixed in a version), and the steps in Coodsz's reply show as a list. Under each answer, **Did this fix it?** has two buttons. **Yes, it's fixed** tells Coodsz it worked. **No, still broken** opens a short form, and what you write, your new logs and a screenshot if you add one go to the same report.

**COOP Server Settings Lock is retired.** It's gone from the Steam Workshop, Nexus Mods and ModDB, so the locked setups no longer use it. If a setup of yours still has it on, the tools tell you to turn it off, and every player needs to turn it off too. Saves made with it still load.
- Where your setup has no MCM values of its own for Xorberax's Legacy, Diplomacy, Settlement Culture Drift or Agriculture Estate, the Server Tool gives them the values Settings Lock used. You can change them under **MCM settings**.
- While you're joined, the MCM settings the host shares stay on the host's values, even if you change them. You get your own values back when you leave.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Coop-Tools-v1.3.4.zip` and copy each program over the old one.

New text is translated into all six languages.
