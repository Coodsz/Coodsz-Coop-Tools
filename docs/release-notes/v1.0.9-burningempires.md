### What is new in v1.0.9

**Coop v0.1.7 is on the Steam Workshop.** Workshop item 3770450698 has had Coop v0.1.7 since October 30, so the tools no longer tell you to get it from Coop's GitHub release.

**Use the Workshop's dedicated server.** The Workshop item comes with its own dedicated server in its `DedicatedServer` folder, and that is the one to use. **Prepare server** copies it. A server you picked with **Choose Coop server** is used instead, unless the Workshop server has a newer Coop. **Download Coop server** under **Advanced: server folder** on the **Settings** page is still there for a server you unzip yourself and pick with **Choose Coop server**.

![The Coodsz Burning Empires download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-BurningEmpires/main/images/Coodsz-BurningEmpires-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.9.zip` and copy each program over the old one.

New text is translated into all six languages.
