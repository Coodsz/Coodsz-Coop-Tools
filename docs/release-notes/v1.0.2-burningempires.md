### What is new in v1.0.2

**Prepare server works with a fresh Workshop download.** After a new download of Bannerlord Coop from the Steam Workshop, **Prepare server** in the Server Tool said "The Coop dedicated server was not found" and asked you to subscribe, even when Coop was there. The Workshop copy of Coop doesn't carry the start script the tool was looking for, and the tool already puts in its own. **Prepare server** now works with it.

If you saw that message after subscribing, update the Server Tool and click **Prepare server** again. You don't need to unsubscribe, clear Steam's download cache or run anything as administrator.

![The Coodsz Burning Empires download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-BurningEmpires/main/images/Coodsz-BurningEmpires-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.2.zip` and copy each program over the old one.

New text is translated into all six languages.
