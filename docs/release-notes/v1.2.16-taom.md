### What is new in v1.2.16

**Server Tool, server rules (on by default now).** The Server Tool now pauses the game while a player joins, and offline players gain no skill XP until they come back. Both are on by default, so a TAOM server behaves differently after this update. Turn them off in **Advanced: server rules** on the **Settings** page. There you can also limit who may use unstuck and protect player kingdoms from AI wars. Kingdom protection keeps your Coop setting until you pick one.

**Server Tool, mod settings for players (on by default now).** Players who join now use your MCM settings for the session, with no setup. Every **Prepare server** and **Start server** copies the MCM values from your own game to the server, except the ones you changed in the tool, which stay as you set them. Before, a TAOM server only shared the War of the Ring state. Change the values for everyone in **Advanced: mod settings for players** on the **Settings** page. Looks mods (interface, graphics or sound) stay each player's own, and players' own files stay as they are. Players need nothing new. The client part comes with the join password module the Client Launcher already puts in place.

**New TAOM.CoopCompat for Bannerlord 1.5.7.** The full TAOM download for Bannerlord 1.5.7 has its own TAOM.CoopCompat. **Install or repair TAOM** and **Start server** now leave it alone and say why. These tools run TAOM 2.0.29.5 on Bannerlord 1.4.8 with Coop 0.1.6.

**Server Tool, TAOM.CoopCompat 0.3.25 put back.** **Start server** now puts back the TAOM.CoopCompat 0.3.25 file or SubModule.xml from the host kit when one is changed or missing. Before, the server stopped the same way on every start. The server window and the crash report now explain both stops.

**Server Tool, console.** Commands the Server Tool sends to the server now go one at a time, in order, and a command still waiting in the tool when the server restarts is dropped instead of going to the new run. When the console is slow, the tool says the command may still arrive instead of saying it failed and sending it again.

**Server Tool, Saves page.** When **Prepare server** or **Choose Coop 0.1.6 server** stops, the **Saves** page now shows why, not only the **Dashboard**. When Windows blocks a DLL the server needs, the tool now opens **Settings**, where the red **Unblock DLLs** button is.

**License.** The license now also names the Coodsz Realm of Thrones tools. You are asked to accept it once more.

**Also.** **Start server** and **Test mods on the server** stop with a plain line when War Sails is turned on, since these tools can't host War Sails. The Realm's **Join on Discord** button opens the new invite, since the old one expired. The Client Launcher no longer shows the join password in the command line it logs on **Connect**. The Server Tool's **Console** output box is tall enough to read again.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.16.zip` from https://github.com/Coodsz/Coodsz-TAOM/releases/latest and copy each program over the old one.

New text is translated into all nine languages.
