## Campaign names in any language, and the server MCM from a turned off download

**For hosts, a new campaign name can use letters from any language.** The AD1259 server tool now takes a new campaign name like YÜZÜK TEST, with letters from any language, numbers, spaces, hyphens and underscores. Path characters are still not allowed. The tool checks the name against the server folder's own start script before the server starts, so if an older copy of that script only takes the English letters A to Z, **Start server** says so in plain words. Pick a name with A to Z, or close anything that has the server folder open and click **Start server** again.

**For hosts, Start server no longer stops on an old server MCM.** When the Coop and Friends launcher on the same PC turned off an old Workshop download of Mod Configuration Menu (MCM), the AD1259 server tool still takes the MCM version the pack needs from it and puts a working copy on the server.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
