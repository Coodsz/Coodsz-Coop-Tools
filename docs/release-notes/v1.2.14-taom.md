### What is new in v1.2.14

**Both tools, the license.** The license now says exactly what counts as a paid server, meaning one that charges players to join or play, or sells perks, ranks, items or priority. It also rules out streams or videos that earn money, from ads, subscriptions, donations or sponsors, unless Coodsz says yes. The tools ask you to accept the license once more. The license itself stays in English.

**Client Launcher, module licenses.** Every Coodsz module folder the Client Launcher puts in place now has a `LICENSE.txt`.

**Both tools, reports.** **Send my logs** and crash reports now list the versions of your Coodsz modules, so a problem is quicker to find.

![The Coodsz TAOM download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-TAOM/main/images/Coodsz-TAOM-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.14.zip` and copy each program over the old one.

New text is translated into all nine languages.
