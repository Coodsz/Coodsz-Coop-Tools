## Everyone plays with the host's mod settings

**Players now use the host's MCM settings by themselves.** When a friend joins a Coodsz Host server with Coop and Friends, their game uses the host's mod settings for that session, so every PC runs the mods the same way. Nothing to set up. It only lives in memory, so their own settings files never change, and hotkeys, interface, sound and camera settings always stay each player's own.

**Hosts get an Advanced area.** Open **Advanced** on the Settings page of Coodsz Host to change a mod's values for players, or untick a mod so players keep their own settings for it. While the server runs, **Apply** sends the change right away. While it is stopped, the change waits for the next launch.

## Get all of the server's mods in one click

**Connect gets the mods the server needs.** When your setup has mods that are missing or out of date, Connect shows one box with the mod names and a **Get them and connect** button. It downloads them through Steam, turns them on in the right order and joins. Mods that are not on the Steam Workshop are listed by name with their **Get it** link, and the game waits until you have them. With nothing missing, Connect works just like before.

## A tidy card when a save needs other mods

**One click fixes a save that needs mods your setup leaves out.** Start server now shows a tidy card on the Home and Server pages with the missing mods as chips and one button that does the fix. It turns the mods back on, switches to the setup the save was made with, or opens Add mods when a mod is not on the server yet. **Use a different save** lets you pick another save instead.

## Tested verdicts from ModderLords

**The Mods page shows what ModderLords tested.** Next to the green and red player counts you now see the verdict from the compat records by Ryvius, like Tested works, Tested broken or Works with settings. It also tells you when he tested an older version than the one you have.

**His tested settings become your defaults.** When Ryvius tested a mod with certain settings, Coodsz Host uses them as the host defaults for players. Anything you set yourself still wins.

## A calmer Your mods card

**The Your mods card is easier to read.** It has one short line, **Add mods** as the main button next to **Check mods** or **Install mods**, and the rest in a **More** menu. **Save mods** only shows while a change is waiting, and a small mod count sits by the title.

## Server rules in Coodsz Host

**The game pauses while a friend joins.** Coodsz Host pauses the campaign while a player joins or loads, so the world does not run on without them, and puts your speed back once they are on the map. It lets go after 3 minutes so a stuck join can't freeze everyone, a player who was on the map once never pauses it again that session, and a game you paused yourself stays paused.

**Offline players stop gaining skill XP.** While a player is offline, their hero gains no skill XP until they come back, so nobody levels up while away. Coop already freezes their gold and food. This part is adapted from ModderLords by Ryvius, with his permission.

**Hosts can limit coop.unstuck.** Under **Advanced: server rules** on the Settings page, Unstuck for players can stay **Allowed** (Coop's own behaviour), or be set to **Not in fights, as a prisoner or near enemies**, which also allows it only once every 5 minutes, or to **Host only**, where you run coop.unstuck with the player's id on the Console page. A player who is refused gets a short chat line saying why. Pause on join and the XP freeze are on by default and can be turned off in the same place.

## One less server crash

**A kingdom with no leader no longer crashes the server.** When a war was declared and a kingdom on either side had no leader, the server shut down with "Failed to run Game.OnTick". It happened on TAOM's War of the Ring day, when Isengard declares war and its allies are asked to join. Coop Save Rescue now lets the war go ahead, gets past the call to war that crashed, and lists it with the other save fixes. It only steps in when the game really crashes there.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
