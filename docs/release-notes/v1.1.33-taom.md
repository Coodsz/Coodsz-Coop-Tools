### What is new in v1.1.33

**Mod setups.** You can now play TAOM with more mods.
- **Plain TAOM** stays the locked default and loads exactly the sealed TAOM-Coop list, the same as before.
- **TAOM plus** is a locked set of mods tested in Coop with TAOM: Better Exception Window, CC's Banners, Banner Fix, Raise your Banner, Raise your Torch, Immersive Battlefields, Dismemberment Plus, Xorberax's Legacy, RTS Camera with its Command System, CoopModPatch and Improved Garrisons. Install mods copies the bundled ones and downloads the Workshop ones.
- **Your own setup.** Click New setup or Copy, then **Add mods**. Extra mods load after TAOM, never inside the TAOM core. Save mods, Share mod list and Import mod list work like in Coop and Friends, and the host imports the same list in the server tool.
- **Mod list** opens the TAOM mod list in four groups (Tested in Coop, Loads on the server, Works in TAOM but not tested in Coop, Risky and Broken) with a search box, where each entry comes from, the day it was checked, a Workshop or Nexus link and **Add to setup**.
- **TAOM community mods and patches with TAOM_ names**, like TAOM_PlayerVoices and the TAOM_Standalone_Compat patches, can be added. Only the modules TAOM and the Coop kit install are refused.

**The launcher does the fiddly parts for you.**
- **Dependency fix.** TAOM.Dependencies already ships Harmony, ButterLib, UIExtenderEx and MCM, so a mod that asks for them would not load. Right before a launch the launcher takes those entries out of the mod's SubModule.xml and puts the original back when the game closes. **Undo dependency fix** is in the More menu.
- **Unblock DLLs runs by itself** before every launch and after Install mods. The button is still in More tools.
- **Load order.** Auto sort puts every extra mod below the TAOM files in the order the TAOM developer asks for, with RTS Camera at the bottom. Connect and Start server stop on a missing or turned off dependency or a known clash, and warn about the rest.
- **Badges.** Each mod shows its TAOM list badge with the note on hover, plus your own result (Worked for you, Crashed for you, Passed on your server). Mods no list knows show Unknown, not tested. Known broken mods ask before they are added.

**When the game crashes.**
- **Find the crashing mod** starts the game to the main menu with half of your extra mods at a time until one mod is left.
- **Safe mode** joins once with Plain TAOM.
- The launcher warns when you join a host that runs other mods than last time.

**Fewer buttons in view.** Setup has one **Install or repair TAOM** button that installs when TAOM or TAOM.CoopCompat is missing or the wrong version and repairs otherwise. **Low FPS fix** is one On and Off switch. Unblock DLLs, the Coop copy tools, Module folder, Clear shader cache and Open client logs are in **More tools**. **Save logs for help** makes the zip to send.

**Server tool.**
- **Edit setups on the server tool too.** The Modules page has New setup, Copy, Rename, Add mods and Save mods, and extra mod rows can move up or down, be removed or switched off, with the same load order rules as the client. Plain TAOM and TAOM plus show a Locked tag. After an edit the tool reminds you to share the mod list with your players.
- **Runs a server with your extra mods.** Plain TAOM still starts the sealed TAOM-Coop server. A setup with extra mods copies them into the prepared server, turns off client only code there and starts the Coodsz TAOM server with the same order players use. The Modules page says which mods every player has to get from Nexus Mods or ModDB.
- **Test mods on the server** tries each ticked mod alone with the TAOM core on a copy of your save named save-modtest, and tells you if it loads. Real saves are not written. Results stay in the window with their date.
- **Stop and Restart wait for the whole save.** The tool waits for the server's own "world saved" line before it stops the server, so the next start no longer rolls back to an older save. Restart warns the players 30 and 10 seconds before.
- **A backup after every save**, kept in save-backups. **Restore save backup** puts one back. A copy is also kept before a save first runs with another mod list.
- **Clear status.** A gold loading bar shows while the server starts. The start banner no longer counts as Serving, and a save that does not load shows FAILED with the reason. Picking a save made on another TAOM, TAOM_Map or LOTRLOME_Armory version shows a warning and asks before Start.
- **CPU and memory line** under the uptime while the server runs.
- **Add mods to a running campaign.** When a setup only adds mods to a save, the tool names them, asks once and keeps a copy of the save before it starts. A save that needs mods the setup leaves out gets a strong warning, because taking mods out can break a campaign, and Start anyway keeps a copy first.
- **Game speed on the Server page.** A card says whether 2x speed and the battle speed limit are on, with buttons to change them and Restart server when it is needed. The Fast forward settings are now a Game speed group at the top of Settings with their own Save settings button.

**Easier joining.**
- The server tool lists the addresses friends can use (Steam lobby, Radmin VPN or Hamachi, public address, same Wi Fi, 127.0.0.1), each with Copy. **Copy invite** makes a short Discord message without the password.
- **Open the port on my router automatically** opens UDP 4200 on your router while the server runs. **Allow through firewall** adds the Windows Firewall rule after you confirm.
- The client fills in **127.0.0.1** when the TAOM server runs on the same PC, and the **?** next to Steam lobby and Direct opens the join guide.

**Fixes.** The Steam line no longer says Steam is closed while steam.exe runs. Set gold falls back to the command the TAOM server has.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.

## Coodsz TAOM tools v1.1.33 for TAOM-Coop 0.3.25

Works with Bannerlord 1.4.8, TAOM 2.0.29.5 (all four modules), Workshop Coop 0.1.6 and TAOM.CoopCompat 0.3.25. TAOM 2.0.27 campaigns do not load on 2.0.29.5, so start a new campaign.

### Players
1. Install the .NET 8 Desktop Runtime x64 from https://dotnet.microsoft.com/download/dotnet/8.0
2. Download Coodsz-TAOM-Client-Launcher-v1.1.33.zip and unzip it.
3. Download TAOM-Coop-v0.3.25-CompatOnly-CLIENT-PLAYTEST-1675bea7-a2ac41c2-r2.zip and leave it zipped.
4. Subscribe to Bannerlord Coop on the Steam Workshop (3770450698) so you get 0.1.6.
5. Download TAOM 2.0.29.5 and leave it zipped, from https://www.moddb.com/mods/tales-from-the-age-of-men/downloads/taom-public-2-0-29-5
6. Open the launcher and click Check mods, Install or repair TAOM, then More tools and Use Workshop Coop 0.1.6. Pick the same mod setup as the host, then Connect (Direct, with the host IP and UDP 4200).

### Host
Do the player steps, then download Coodsz-Dedicated-TAOM-Server-Tool-v1.1.33.zip and TAOM-Coop-v0.3.25-CompatOnly-HOST-OPERATOR-1675bea7-a2ac41c2-r2.zip (leave it zipped). Make a new 2.0.29.5 campaign in single player, pick it, then Prepare server, Start server, and click I accept on the Coop server terms. Give players your IP and UDP 4200, or use Copy invite. Steam lobby is optional (tick Advertise through Steam).

The full instructions are in README - Instructions.txt below.
Already have the tools? Click Install update, or unzip over your old folder and choose Replace.

Code from CoopKeep by aderimo (MIT) is used for the server events and backups. See THIRD-PARTY-NOTICES.md in the zip.
