### What is new in v1.0.10

**Client Launcher on Coop 0.1.7.** The status at the top no longer stays on Joining while you play. When Coop's client log stays empty, it says Game open instead.

**Send my logs.** It also packs the newest three numbered Coop client logs that Coop 0.1.7 writes, so the tool can spot a known problem in them.

![The Coodsz Burning Empires download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-BurningEmpires/main/images/Coodsz-BurningEmpires-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-Burning-Empires-Tools-v1.0.10.zip` and copy each program over the old one.

New text is translated into all six languages.
