### What is new in v1.1.49

**Server keeps running when a clan is destroyed.** The server no longer stops when a clan is destroyed and one of its heroes can't be taken off a party's troop list. This happened about one game day after loading some TAOM saves. Coop Save Rescue, which the server tool already loads on every start, now skips that one change, writes a line about it in the server log, and the game goes on. Update the server tool and load your save again.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
