### What is new in v1.1.47

**Crash reports ask for your Discord name.** Send crash report and Send my logs in the TAOM client launcher and server tool now have a box for your Discord name right above Send. Send waits until the box has a name. Coodsz uses it to contact you about the report, and people who can read the report can see it.

**You only type it once.** The tool keeps the name on your PC and fills it in the next time. Save a copy still works without a name.

Players still need the TAOM-Coop CompatOnly CLIENT zip and the host the CompatOnly HOST-OPERATOR zip. Both are attached to this release again, the same files as before.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
