## Updates keep your other tools and files

**Updates no longer remove another Coodsz tool or your own files.** From this version on, **Install update** removes only the files that belong to the tool you update: its own program and the files that came with it. Another Coodsz tool in the same folder stays, and so does any file of your own.

Keep each Coodsz tool in its own folder. This one update is still installed by the version you have now, so it can still remove another Coodsz tool or a program file of your own (.exe or .dll) in the same folder. If a Coodsz tool goes missing, unzip it again from its release zip.

New text is translated into all six languages. Click **Install update** in the tool, or unzip over your folder and choose Replace.
