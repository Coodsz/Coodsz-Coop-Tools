### What is new in v1.2.10

**Host TAOM again while Steam has Coop v0.1.7.** TAOM.CoopCompat 0.3.25 still needs Coop v0.1.6. The Server Tool can now prepare and start a TAOM server from a Coop 0.1.6 dedicated server you download yourself.

1. Download the Coop 0.1.6 dedicated server from Coop's GitHub release or from Nexus Mods (archived files):
   https://github.com/Bannerlord-Coop-Team/BannerlordCoop/releases/tag/v0.1.6
   https://www.nexusmods.com/mountandblade2bannerlord/mods/11879?tab=files&category=archived
2. Unpack it with 7-Zip.
3. In the Server Tool, open the **Saves** page and click **Choose Coop 0.1.6 server**. Pick the folder you unpacked.

The tool takes the folder only when it holds the released Coop 0.1.6. **Prepare server** and **Start server** copy from it and never change it.

**Coop line on the Play page.** When Coop is the only problem, **Check mods** in the Client Launcher now shows the Coop line on the **Play** page instead of only in the log. On Steam's Coop 0.1.7 that line says TAOM in Coop waits for a TAOM.CoopCompat made for it.

**Client Launcher on Coop 0.1.7.** The status at the top no longer stays on Joining while you play. When Coop's client log stays empty, it says Game open instead. **Send my logs** also packs the newest three numbered Coop client logs that Coop 0.1.7 writes.

![The Coodsz TAOM download, one zip that unzips into a folder with the Server Tool and the Client Launcher](https://raw.githubusercontent.com/Coodsz/Coodsz-TAOM/main/images/Coodsz-TAOM-new-download.png)

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.10.zip` and copy each program over the old one.

New text is translated into all six languages.
