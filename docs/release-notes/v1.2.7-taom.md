### What is new in v1.2.7

**A new look.** Both tools have a sidebar with their pages and the dwarven gate behind them. The Server Tool opens on the new **Dashboard**, with **Saves**, **Mods**, **Settings**, **Cheats**, **Console**, **Logs** and **Guides** under it. The Client Launcher opens on **Play**, with **Mods**, **Logs and help**, **Settings** and **Guides**. Only one notice shows at a time.

**Another Coop is set aside only when you say so.** When another Coop, like Coop v0.1.7 for the Coop or AD1259 tools, is in the game's Modules folder, the Client Launcher now asks first, with **Set aside and play**, **Cancel** and **Don't ask again**. What it set aside goes back into Modules when you close the launcher. **Restore parked Coop** is only for a Coop that did not come back.

**Start server puts a TAOM.CoopCompat file back.** When antivirus removed a TAOM.CoopCompat file from the server, **Start server** now puts it back from the tool's own copy. If it goes again, click **Fix antivirus**.

**The hosted save no longer switches without a word.** The Server Tool now asks before **Name server copy** copies, or **Start server** hosts, a save that is earlier in the campaign than the one the server last ran. The save list shows each save's campaign day.

**Locked while the server runs.** On the **Mods** page the switches, the move and remove buttons, **Save mods** and **Install mods** are off while the server runs. **Prepare server** now says to stop the server first instead of changing its files.

**Dashboard cards.** The Server Tool's **Dashboard** has a **Mods** card with how many mods are on, and a **Made for** card with the Bannerlord, Coop and TAOM versions these tools are made for, with a green tick when the server matches. The Client Launcher's **Play** page has the **Made for** card too.

**The crash report bar waits.** When the Server Tool tries a load crash again by itself, the **Send server crash report** bar waits for that try and shows only if it crashes too.

**Smaller fixes.** The mod list chips have clearer words. Required is now **Always on**. When the host has no mod settings to share, the server now says so, and the player's game no longer waits 30 seconds for them. **My reports** keeps checking for answers after the PC clock was set back.

### How to update

Click **Install update** in the Server Tool and the Client Launcher. Or download `Coodsz-TAOM-Tools-v1.2.7.zip` and copy each program over the old one.

New text is translated into all six languages.
