# Discord announcement, Coop and Friends v1.2.53

Paste the text inside each block as its own message, the first one first. Each stays under 2000 characters, has no colons and no hyphens between words.

```
**Coodsz Coop and Friends v1.2.53 is out**

Big one this time. Click Install update in the tool and you get all of it.

**Joining is a lot easier**
Coodsz Host now shows every address your friends can use, each with a Copy button. Copy invite puts a ready message for Discord on your clipboard, and it never includes your password. The tool can open the server port on your router by itself while the server runs, and Allow through firewall adds the Windows rule for you. If you play on the same PC as the server, the launcher fills in 127.0.0.1 for you. Not sure how your friends should join? Press the ? button and it walks you through Steam lobby, same Wi Fi, Radmin or Hamachi and port forwarding.

**The server looks after itself better**
You can turn on Restart the server if it crashes. Your campaign gets a backup after every save, and Load backup puts one back. Stop and Restart now let the server save first, and Restart warns players 30 and 10 seconds before. The status no longer says SERVING before the server is actually ready, and there is a small CPU and RAM line while it runs.

**Settings and mods**
Every Coop setting is on the Settings page now, and they are kept for each campaign save. Mods show a community badge like Works or Broken, and you can click it to report how a mod went for you. Next to it you see your own result, like Worked for you or Crashed for you. Coodsz Host can also test mods on the server for you, one at a time on a throwaway campaign, so you know what loads before your friends join.

**Small fixes**
Adding Diplomacy.CoopCompat to a running campaign no longer hides your save. Save logs for help is now one button in the launchers. The Steam line stops saying Steam is closed when it is running.

Thanks to aderimo for CoopKeep. A lot of the server work is built on it. Let me know in this thread if anything acts up.
```

```
**And there is more in Coodsz Host**

**New pages**
Home is the first page now, with one big Start button, Save game, Backup now, Restart and who is online. Create a world walks you through a new campaign or a single player save. The Players page has search, profiles, cheats and bans in one place. The new Cheats page gives or takes gold, health, troops, skills and items for one player or several. The Map page draws the running campaign live with kingdoms, lords, armies and battles, and the Encyclopedia lets you browse heroes, clans, towns, troops and items. Guides has six short help pages.

**Handy extras**
World presets fill in Casual, Standard or Hardcore settings with one click. Streamer mode hides IPs, codes, Steam ids and the password so you can stream the window. Filter chips on the Modules page show only the mods you want to see.

**Mods and saves**
You can now add mods to a running campaign. Start server asks once and keeps a backup first. A save that is missing one of its mods is still refused, because taking mods out can break it. Locked setups show a Locked tag, and the community list has the Coop 0.1.6 verdicts from the compatibility thread.

**Game speed**
The Server page shows whether 2x speed and the battle speed limit are on, with buttons to change them and a Restart server button when it is needed.
```
